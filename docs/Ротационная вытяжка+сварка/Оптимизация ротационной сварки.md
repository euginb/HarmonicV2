# Оптимизация параметров ротационной сварки трением сталей 32Г2 и 40ХН2МА

Конспект статьи для анализа ИИ. Источник: `docs/Ротационная вытяжка+сварка/Оптимизация ротационной сварки.pdf`
(5 страниц, с. 173–177 сборника «Уральская школа молодых металловедов», секция 1 «Термическая обработка
сталей и сплавов»).

## Задача

РСТ — высокопроизводительная технология неразъёмных соединений; в геологоразведке и нефтяной
отрасли ею соединяют замковую часть с телом бурильной трубы из среднеуглеродистых легированных
сталей. Зона шва — самое уязвимое место: нужен подбор режимов.

## План эксперимента

Четырёхфакторный эксперимент, 27 опытов (по 3 серии на сочетание).

| Фактор | Обозначение | Диапазон |
|---|---|---|
| Сила разогрева | Fр | 55…145 кН |
| Сила проковки | Fпр | 145…360 кН |
| Частота вращения при разогреве | n | 400…1000 об/мин |
| Длина оплавления | l | 4…10 мм |

Материалы и заготовка: труба **Ø73×9 мм**, сталь **32Г2** — тело трубы, сталь **40ХН2МА** — замковая
часть. Оборудование: автоматизированная машина для сварки трением **Thompson‑60** (АО «Завод
бурового оборудования»).

## Испытания

Статическое растяжение цельных образцов по ГОСТ 6996–66 (рабочая часть 15×50 мм) и образцов с
V-образным концентратором, нанесённым в зоне контакта с двух сторон.

Наблюдение: цельные образцы разрушались как в стыке, так и в ЗТМВ **со стороны 32Г2**, поэтому
уравнения регрессии по временному сопротивлению стыка получены только для образцов с V-концентратором.

## Результаты

| Результат | Содержание |
|---|---|
| Значимость факторов (карта Парето) | наибольшее влияние на функцию отклика — **сила разогрева Fр** и **сила проковки Fпр** |
| Микроструктура | видны линия стыка и ЗТМВ протяжённостью **≈3.5 мм**, далее основной металл |
| Со стороны 40ХН2МА у стыка | игольчатый мартенсит |
| Со стороны 32Г2 у стыка | смешанная мартенсито-бейнитная структура |
| Причина закалочных структур | локальный разогрев выше температуры полиморфного превращения + ускоренное охлаждение за счёт теплоотвода в холодный металл → фазовые превращения в твёрдом состоянии |
| По мере удаления от шва | волокнистое строение: чередование полос закалочной структуры и мелкодисперсной феррито-цементитной смеси |
| Микротвёрдость | у 40ХН2МА вблизи контакта высокая (мартенсит), плавно снижается до уровня основы; ЗТМВ 32Г2 — **зона разупрочнения** относительно своего основного металла |
| Показательный режим (рис. 1, 2) | Fр = 100 кН, Fпр = 260 кН, n = 1000 об/мин, l = 10 мм |

Авторы отмечают, что для объяснения разрушения цельных образцов в стыке при отдельных режимах
нужны дальнейшие фрактографические исследования.

## Что это значит для нашего проекта

| Вывод статьи | Следствие для стакана-ступицы (TECH-03) |
|---|---|
| ЗТМВ ≈ 3.5 мм с мартенситом у 40ХН2МА | шов нельзя оставлять в зоне циклического изгиба; после сварки обязательна полная ТО (закалка + высокий отпуск) |
| Зона разупрочнения возникает на стороне менее легированной стали | легирование присоединяемого металла не должно быть ниже основы, иначе шов «слабнет» не по стыку, а рядом |
| Сила разогрева и сила проковки — главные факторы | при подборе режимов начинать с них, частоту и оплавление подбирать после |
| Толщина 9 мм варилась успешно | тонкую стенку 0.88 мм варить нельзя — режим не переносится, нужен «толстый» этап заготовки |
| Испытания — растяжение, не выносливость | прочность стыка на усталость статьёй **не подтверждена** → OQ-38 |

## Ограничения конспекта

Уравнение регрессии и абсолютные значения временного сопротивления стыка в извлечённом тексте
отсутствуют (в PDF приведены графически/в обработке), поэтому в конспект не переносились. Для расчёта
коэффициента прочности шва нужен полный текст статьи с таблицами.
