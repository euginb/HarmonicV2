# ТЗ на расчёты МКЭ (ПТК, венец и сепаратор)

Статус: **выпущено** (2026-11-27, rev16.0, CP-138, Д-154). Исполнитель — инженер-расчётчик
или внешняя модель; решатель — CalculiX через FreeCAD FEM (`docs/МКЭ/КАК-МКЭ-в-FreeCAD.md`).

Документ задаёт **что считается и по какому критерию результат принимается**. Методика
настройки решателя — отдельный документ; здесь только постановки и приёмка.

## 1. Зачем и что закрывает

Сегодня «после МКЭ» стоит условием в четырёх решениях и двух вопросах, но нигде не сказано,
что именно считается и когда результат считается годным. Это дыра: расчёт можно выполнить
формально и подписать «МКЭ подтверждает», не имея критерия.

| Закрывает | Постановка | Выход, который входит в код |
|---|---|---|
| OQ-51 — `k_w`, схема опоры `free`/`pack` | Р-1, Р-5 | `limits.ring_twist_k`, `ring_row_eps`, `k_w` |
| Д-151 — Ø203 против Ø194 | Р-2 | выбор наружного Ø, масса |
| OQ-46, CP-137 — пояс сепаратора по `hb` | Р-3 | предел `M_sep` по поясу |
| Д-152, CP-135 — зубья крышки | Р-4 | `h_z`, ширина 20, податливость стыка |
| Д-152 — фреттинг в посадке 0…5 мкм | Р-4 | амплитуда проскальзывания |

Расчёт **не отменяет** формулы `ptk_force.py`. Формула даёт номинальное напряжение при
заданной форме деформирования; МКЭ даёт фактическое распределение. Если они расходятся
больше чем на 20 %, это не «уточнение», а сигнал, что одна из моделей описывает не тот
механизм — разбираться обязательно (см. §4).

## 2. Общие правила постановки

| Параметр | Требование |
|---|---|
| Единицы | мм, Н, МПа, т, с (согласованный набор). Плотность стали — **7.85e-9 т/мм³**, не 7850. Момент — в Н·мм: `M_req` 1100 Н·м = **1.1e6 Н·мм** |
| Тип анализа | линейно-упругая статика; контакт — только в Р-3 (пояс/окна) и Р-4 (зуб в паз) |
| Материал | E = 210 000 МПа, ν = 0.3, ρ = 7.85e-9 т/мм³. σ_0.2: ШХ15 — 1670 МПа (`materials.yaml`), 40Х улучшение — 785 МПа. **ШХ15СГ: σ_в и σ_0.2 не подтверждены (OQ-36) — до сверки принимать как ШХ15 и указывать это в отчёте** |
| Элемент | C3D10 (тетраэдр 2-го порядка), не линейный C3D4 |
| Сетка | не менее **4 элементов по толщине стенки**; в зоне контакта ≤ 0.5 мм; локальное сгущение — Gmsh `MeshRegion` |
| Сходимость | сгущение ×2 по всему телу, изменение контролируемого напряжения **< 5 %**; отчёт по двум сеткам обязателен |
| Съём результатов | по **путям и сечениям**, не «максимум по модели»: у заделки и у ребра всегда сингулярность |
| Запрещено без отдельного решения | пластика, остаточные напряжения закалки, ползучесть, динамика. Первый прогон — только упруго, иначе не с чем сверять |

## 3. Постановки

### Р-1. Глобальная жёсткость венца (OQ-51)

| Пункт | Задание |
|---|---|
| Геометрия | венец `.01` по Д-151, монолит Ø203×105, профиль по SPEC-10 (коммит фиксируется в отчёте) |
| Модель | сектор 90° с симметрией на плоскостях реза (гасит моды m = 1, 2, 3 — см. §6), полная модель — контрольный прогон |
| Опора | 8 торцевых зубьев по Д-152: заделка по боковым граням; альтернатива — контакт с жёсткой плитой. **Считать оба варианта**, разница показывает, какая доля податливости в стыке |
| Нагрузка | 32 силы на ряд × 4 ряда, тангенциально, по площадке контакта (не в точку): при `M_req` F = 416 Н на тело (R_Σ 82.55); при `M_ov` 892.9 — 338 Н |
| Выход | угол закрутки φ при M = 735.1 / 892.9 / 1100 Н·м; радиальный прогиб обода; `k_w` |
| Критерий | φ приведён в угл. минутах; `k_w = 2n·φ_рад/π` при n = 32; Δθ_доп — от заказчика (OQ-51), расчёт даёт фактический угол, не допуск |

Контрольная цифра до расчёта: брутто-оценка кручения трубы по Бредту даёт τ ≈ 1.4 МПа и
φ ≈ 0.07′ при 1100 Н·м (A_m 28 040 мм², t 14.05, J 7.49e7 мм⁴). Значит глобальное кручение
**не является** механизмом, ограничивающим `M_req`; ограничивают локальный изгиб у точек
контакта, овализация от дискретной опоры (8 зубьев) и податливость стыка. Если МКЭ покажет
в стенке сотни МПа — это изгиб, и его надо предъявить как изгибное напряжение с путём съёма,
а не как «уточнённое кручение».

### Р-2. Стенка монолита: Ø203 или Ø194 (Д-151)

| Пункт | Задание |
|---|---|
| Геометрия | два варианта: стенка 14.05 (Ø203) и 9.55 (Ø194), профиль одинаковый |
| Нагрузка | `M_req` 1100 Н·м + овализация: радиальные силы от тел на 4 ряда с фазами 0/90/180/270 |
| Выход | τ_max в стенке на пути «середина стенки по высоте», σ_экв, радиальный прогиб между зубьями |
| Критерий | запас `n_τ = (σ_0.2/√3)/τ_max ≥ 2` для Ø194; при невыполнении — остаётся Ø203. Для Ø203 отчёт без порога, но с запасом |
| Что не считается | концентрация у пазов под крышку — отдельная постановка CP-135 |

### Р-3. Сепаратор: пояс по оси `hb` (OQ-46, CP-137)

| Пункт | Задание |
|---|---|
| Геометрия | стакан `.02` + `.12` по TECH-01, пояс по `band_h_list` (0…8 мм), радиальная толщина **не более 3.34…3.6 мм** (коридор Д-150) |
| Материал | 40Х улучшение, σ_0.2 785, σ₋₁ 509 МПа |
| Нагрузка | сила на шаг окон `q = M/(u·R_Σ)`; при 1100 Н·м — 416 Н на окно, распределена по площадке контакта тела |
| Модель | сектор по шагу окон (11.25°) с симметрией, 3–4 варианта `hb` |
| Выход | σ_max в поясе и в стенке, τ в поясе, путь от окна к ступице; предел `M_sep` при `n = 1.5` по σ_max |
| Критерий | `M_sep ≥ M_req` при `hb` из сортамента; если ни один `hb` не даёт — вопрос к заказчику, а не «подкрутить предел» |
| Сверка | формула `τ = 3M/(2πR·t·h)` из `ptk_force.py` — расхождение до 15 % допустимо, больше — разбираться |

### Р-4. Зубья крышки и стык (Д-152, CP-135)

| Пункт | Задание |
|---|---|
| Геометрия | сектор 45° (один зуб из 8), `h_z` 6, ширина 20, R0.5 в углах ножки |
| Модель | контакт «зуб — паз», трение 0.15; посадка 0…5 мкм — два прогона (номинал и максимум натяга) |
| Нагрузка | `M_R = M·(u+1)/u` = 758 Н·м при 735 и **1134 Н·м** при 1100, распределён по 8 зубьям |
| Выход | σ в ножке, σ_см на рабочей грани, τ_ср, относительное проскальзывание на цикле (амплитуда, мкм), податливость стыка (угол на Н·м) |
| Критерий | σ_см ≤ 0.5·σ_0.2 (K = 2) = 392 МПа; τ_ср ≤ 0.25·σ_0.2 = 196 МПа; амплитуда проскальзывания **≤ 5 мкм** (иначе фреттинг-коррозия, и материал крышки 40Х не годится) |
| Замечание | ориентир Д-152: σ_см 68 МПа, τ_ср ≈ 20 МПа — это оценка по площади 45 мм². МКЭ должен дать тот же порядок; расхождение в 3 раза — ошибка площади или плеча |

### Р-5. Пакет 4 ряда: связь и податливость (CP-136)

| Пункт | Задание |
|---|---|
| Геометрия | полная модель 4 рядов венца со стыками; вариант — связанный пакет (монолит) |
| Нагрузка | как Р-1, фазы 0/90/180/270, эксцентриситеты `e_p` ≤ 5 мкм |
| Выход | `ring_twist_k` (податливость на кручение), `ring_row_eps` (доля момента, передаваемая соседнему ряду), `M_ov` пакета |
| Критерий | `M_ov` по МКЭ против 892.9 Н·м из CP-130 — расхождение ≤ 15 %; при большем — объяснить механизм (стык, зубья, овализация) |

## 4. Обязательные проверки (без них расчёт не принимается)

| Проверка | Как | Порог |
|---|---|---|
| Равновесие | сумма реакций в опорах = приложенный момент и силы | расхождение ≤ 0.1 % |
| Сходимость по сетке | два прогона, ×2 элементов | изменение σ ≤ 5 % |
| Сверка с аналитикой | τ по Бредту 1.4 МПа; герцевские `b_H`, `z_τ` из `_hertz`; срез пояса по формуле `ptk_force` | 10…15 % по интегральным величинам |
| Единицы | момент Н·мм, плотность т/мм³, размеры мм | пересчёт в отчёте показан явно |
| Независимость | расчёт повторён на второй сетке или другим решателем/постановкой | совпадение контролируемой величины ≤ 10 % |

Если проверка не проходит — расчёт возвращается исполнителю. «Красивая картинка» без
таблицы проверок не рассматривается.

## 5. Что сдаётся

Полный комплект — в репозиторий, в папку `fea/<ID>/<постановка>/`:

| Файл | Обязателен | Содержание |
|---|---|---|
| `report.md` | да | постановка, входные данные, сетка (число элементов, размер), таблица результатов, таблица проверок §4, вывод, что меняется в `limits` |
| `job.inp` | да | вход CalculiX — текстовый, воспроизводимый, лежит в git |
| `case.FCMacro` | да, если модель строилась в FreeCAD | скрипт построения постановки (геометрия, материал, сетка, ГУ, нагрузка) |
| `*.png` | да | поле σ_экв, путь съёма, эпюра по пути |
| `*.FCStd` | нет | если > 5 МБ — в `archive/`, не в git |
| `.frd` | нет | результат; при необходимости — `ccx2paraview` или `cgx` |

В отчёте обязательно: **ID конфигурации и sha коммита геометрии**, на которой считалось.
Расчёт без этой привязки к делу не принимается — он устаревает молча (так уже случилось с
`specs/ptk_designs.yaml`, собранным под другой подшипник).

## 6. Ограничения метода (что МКЭ здесь не даёт)

- **Секторная модель гасит моды m = 1, 2, 3.** Для 32 тел и 8 зубьев это допустимо (возбуждаются
  m = 4, 8, 12, 16, 32), но если поле окажется чувствительным к низким модам — контрольный
  прогон полной моделью обязателен. Это записывается в отчёт, а не подразумевается.
- **Остаточные напряжения закалки и ЭЭО** не моделируются. Прочность зуба и стенки считается
  от номинального σ_0.2 без учёта наклёпа/отпуска поверхностного слоя.
- **Фреттинг** оценивается через амплитуду проскальзывания, а не через ресурс: ресурс — только
  по испытаниям.
- **Усталость** — не МКЭ, а критерий по σ₋₁ и коэффициентам концентрации; МКЭ даёт только
  коэффициент концентрации для него.
- **Податливость стыка** сильно зависит от принятой модели заделки; поэтому два варианта
  (заделка/контакт) и требование показать оба.

## 7. Порядок и сроки

| Шаг | Кто | Выход |
|---|---|---|
| 1. Проверка готовности решателя (тест-балка) | исполнитель | скриншот/лог, 15 мин |
| 2. Р-1 на секторе, две сетки | исполнитель | `k_w`, φ(M) |
| 3. Р-2 два Ø | исполнитель | выбор Ø, запас n_τ |
| 4. Р-3 перебор `hb` | исполнитель | `M_sep(hb)`, рекомендация |
| 5. Р-4 зуб, два натяга | исполнитель | σ_см, проскальзывание, податливость |
| 6. Приёмка §4 | заказчик | подпись или возврат |
| 7. Внесение чисел в `limits` | модель (патч) | новый прогон `calc`, SPEC-10 |

Оценка трудозатрат: Р-1…Р-3 — 3–4 дня, Р-4 — 1–2 дня, Р-5 — 2–3 дня. Модели маленькие
(сектор — десятки тысяч элементов), счёт — минуты. Основное время уходит на сетку и проверки,
а не на решение.
