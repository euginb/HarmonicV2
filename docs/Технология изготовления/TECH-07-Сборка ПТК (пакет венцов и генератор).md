## Сборка ПТК: венец, сепаратор, генератор

Статус: **предзаполнен и отредактирован по первому разбору модели** (2026-11-27, серия «Венец .01», rev16.0). Базовая схема — **монолит** (Д-151); стопка венцов на прямом зубе — запасной вариант (Д-153). Порядок сборки изменён по Д-150: сепаратор ставится первым и на него надвигается венец.

Документ — рабочая гипотеза, а не маршрут. Пункты **Р-N** и **OQ** закрываются до запуска в производство. Изготовление деталей — TECH-01 (сепаратор, узел `.02`/`.12`), TECH-02 (электроды ЭЭС), TECH-03…TECH-05 (заготовки). Расчёт — SPEC-10; компоновка — `egm/ptk_layout.py::axial()`; цифровая сборка — Д-49.

Схема венца: крепёж из венца убран, наружный Ø «чёрный», центрирование — по торцевым зубьям (Д-145), межрядные шайбы `.05` сняты (Д-144). Пояс сепаратора усиливается **по оси (`hb`), не по радиусу** (Д-150, CP-137).

### 3. Монолит или стопка

**Базовая схема — монолит (Д-151).** Причины:

1. Только монолит даёт схему `pack` в полном виде: сплошная оболочка связывает все ряды на радиальный сдвиг.
2. Сборка монолита не требует нагрева: венец надвигается на сепаратор сверху, тела ставятся через окна изнутри.
3. Ремонтное преимущество стопки мнимое — соединение натягом неразборное, замена всё равно пакетом.

Ограничения монолита, которые надо закрыть до запуска:

| Ограничение | Состояние |
|---|---|
| Прокаливаемость стенки 14.05 мм при `s_hard_max` 14 у ШХ15 | Ø203 — ШХ15СГ или ШХ15 со свидетелем (твёрдость в середине стенки ≥ 58 HRC); Ø194 (стенка 9.55) проходит по ШХ15 |
| Коробление при ХТО | черновой профиль до ХТО с припуском 0.5…0.8 мм на сторону; коробление съедает припуск, поводку от снятия напряжений снимают чистовые проходы |
| ЭЭО профиля насквозь 105 мм | обычная высота для проволоки; конусность и прямолинейность ≤ 5 мкм на 105 мм после чистовых; основной проход ≈ 6.5 ч, с чистовыми 12…15 ч |
| Поставщик | условие: высота ЭЭО ≥ 120 мм, конусность ≤ 5 мкм (OQ-58) |

Стопка (Д-153) остаётся на случай отказа по этим условиям.

### 4. Соединение с крышкой

Венец не имеет крепёжных отверстий: момент реакции идёт венец → торцевой зуб → крышка → крепёж крышки → корпус. Параметры (Д-152, проверка — CP-135):

| Свойство | Значение |
|---|---|
| Число зубьев | 8 (чётное — режется проволокой вдоль диаметра) |
| Грани | плоскость через ось; вылет по оси `h_z` 6 мм, ширина по окружности 20 мм |
| Радиальный пояс зуба | r 89.5…97.0 (h_r 7.5; от впадин остаётся 2.05 мм стенки) |
| Площадь грани | 45 мм², радиусы в углах паза R0.5 |
| Посадка | переходная 0…5 мкм |
| Материал крышки | 40Х улучшение 28…32 HRC (или 45 с ТВЧ зубьев) — против 60 HRC венца по фреттингу |
| Момент через крышку | `M_R = M·(u+1)/u` — 758 Н·м при 735, 1134 Н·м при 1100 |
| Смятие | 68 МПа при K = 2; срез зуба ≈ 20 МПа |

### 5. Последовательность сборки

Сборка вертикальная. База — крышка выхода `.07B` с подшипником `.09` на ложементе: чашка у выходного торца остаётся вне венца и может быть толстой.

| Этап | Что делается | Выход |
|---|---|---|
| **Э0** | Подготовка: входной контроль, чистка, маркировка | детали и метки |
| **Э1** | Крышка `.07B` с `.09` — на ложемент, метка 0 | база сборки |
| **Э2** | Сепаратор ступицей вниз, ступица в `.09` | сепаратор посажен |
| **Э3** | Надвигание венца на сепаратор до зубьев крышки B, по метке 0 | венец + сепаратор |
| **Э4** | Тонкая плёнка смазки на профиль через окна | смазанный профиль |
| **Э5** | По рядам снизу вверх: тела со смазкой → узел эксцентрика по оправке → кольцо `.11` | генератор собран |
| **Э6** | Вал `.15`, подшипники `.10` | кинематика |
| **Э7** | Крышка A, затяжка, контроль, обкатка | изделие |

#### Э0. Подготовка

1. Входной контроль венца: профиль и пазы без забоин; твёрдость 58…62 HRC (свидетель ХТО); круглость расточки; биение торцов; метка «впадина 0» и номер плавки/садки.
2. Контроль калибрами: сепаратор по калибр-кольцу Ø168.7 (проходит), узел эксцентрика по калибру Ø161.5.
3. Обезжирить и промыть профиль, пазы и расточку; сушка; защита от пыли.
4. Температура деталей 20 ± 5 °C. Комплектность: венец, сепаратор, 128 тел, 4 узла эксцентрика, 3 кольца, вал, крышки, крепёж.
5. Ложемент по уровню; метка 0 ложемента — база на всю сборку.

#### Э1–Э2. Крышка B и сепаратор

1. Крышка `.07B` с подшипником `.09` — на ложемент, метка 0.
2. Сепаратор — ступицей вниз, ступица в `.09`: посадка скольжения или подогрев кольца подшипника. Запрессовка сквозь стопку недопустима.
3. Контроль: сепаратор сел до упора, окна ряда 1 стоят по впадине 0 (шаблон), осевого перекоса нет.

#### Э3. Венец на сепаратор

1. Перед надвиганием проверить калибром: зазор расточки венца к стенке сепаратора не меньше 0.3 мм по всей высоте (коридор Д-150).
2. Надвинуть венец сверху по метке 0 до зацепления с зубьями крышки B. Без нагрева.
3. Контроль: венец сел до упора, проворот от руки, осевого люфта по зубьям нет.

#### Э4. Смазка

1. Тонкая плёнка на профиль через окна — до установки тел. Толстый слой недопустим: при вводе он сдирается и сгоняется вниз.
2. Основной объём — в окна вместе с телами в Э5 (заодно держит тела).
3. Марка — OQ-10: NLGI 2, присадки EP, база ISO VG 150…220 (предварительно).

#### Э5. Тела и эксцентрики по рядам, снизу вверх

Узел эксцентрика собирается вне изделия: `.03` + подшипник `.08` + обод `.18` (при `gen = rim`); тела катятся по ободу. Заходные фаски на ободе — рекомендуется 0.5×30°.

| Шаг | Операция | Контроль |
|---|---|---|
| 1 | Вставить 32 тела ряда k через окна изнутри, со смазкой | 32 из 32, без перекоса |
| 2 | Опустить узел эксцентрика k по оправке; шпонка ориентирует паз | габарит узла при вводе `D_г/2 + a_ω` = 80.45 ≤ 80.75 (r_in пояса) |
| 3 | Провернуть эксцентрик так, чтобы тела вышли в профиль — «подпереть» | все 32 тела в профиле, проворот от руки |
| 4 | Надеть кольцо `.11` (для k < 4) | осевой зазор по `axial()` |

Тело заперто в закрытом окне (20.05 × 7.05): буртик и загиб окна не нужны, при сборке от падения внутрь его держит смазка (Р-7 снят).

#### Э6–Э7. Вал, крышка A, контроль

1. Вал `.15` — сверху, вытесняя оправку; шпонка входит в пазы всех четырёх эксцентриков.
2. Подшипники `.10`; контроль осевого люфта вала по `axial()`.
3. Крышка A — по метке 0; затяжка крест-накрест в 2–3 прохода, момент — задать (OQ-56).
4. Обкатка: 30 мин без нагрузки, 30 мин при 25 % M; контроль температуры подшипников, магнит на стружку.

#### Стопка (запасной вариант, Д-153)

Стопка собирается заранее и надвигается на сепаратор как целое.

| Нагрев | Охлаждение | Стыки |
|---|---|---|
| Н-1: венцы 1 и 3, 125 ± 5 °C | венцы 2 и 4, −78 °C (сухой лёд, осушенный азот, без инея) | 1\|2 и 3\|4 |
| Н-2: пара 1+2, 125 ± 5 °C | пара 3+4, −78 °C | 2\|3 |

Циклы на венец: 1 — два, 2 — один, 3 — один, 4 — ноль. Без охлаждения вставляемых деталей натяг не закрывается: при w = 20 мм и ΔT = 110 K доступно 25 мкм против требуемых 42.

### 6. Термика (только для стопки)

Условие сборки:

Δw_доступн = α·(T_нагр − T_охл)·w ≥ δ_ном + 2·e_p + c_ввода

где α = 11.5·10⁻⁶ 1/K, δ_ном — номинальный натяг, e_p — ошибка шага, c_ввода — зазор на ввод.

Для w = 20 мм: +130 / −78 °C даёт 47.8 мкм, требуется 22 + 10 + 10 = 42 мкм — проходит. При нагреве без охлаждения (ΔT = 110 K) доступно 25 мкм — не проходит.

Требования:

- отпуск венца — не ниже T_сборки + 40 K, то есть 170…180 °C при 58…62 HRC;
- обработка холодом −70 °C в составе ХТО обязательна: иначе охлаждение при сборке даст превращение остаточного аустенита и рост размеров;
- перепад по окружности ≤ 10 K (на w 20 мм это 2.3 мкм); печь с циркуляцией, выдержка до разброса трёх термопар ≤ 10 K; индуктор — только с вращением и той же выдержкой;
- брак — падение твёрдости более 1 HRC; свидетель — на каждой садке ХТО.

Для монолита раздел не действует: нагрев не применяется.
