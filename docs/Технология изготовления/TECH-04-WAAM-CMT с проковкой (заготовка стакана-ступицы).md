## TECH-04 — WAAM/CMT с межслойной проковкой: заготовка стакана-ступицы

Исследовательская ветка, не основной путь (Д-115). Здесь собрано, что метод может и чего не может
для нашей детали, чтобы не возвращаться к вопросу каждый раз, когда усталостная прочность снова
окажется в центре.

Статус данных: ориентировочные режимы, взятые из общей практики WAAM/CMT; в проекте **не
подтверждены** ни экспериментом, ни литературой с числами по 40ХН2МА. Всё, что помечено «оценка»,
подлежит проверке до попадания в калькулятор.

### Что это

| Термин | Расшифровка | Роль |
|---|---|---|
| WAAM | Wire Arc Additive Manufacturing — дуговое аддитивное наращивание проволокой | послойное наращивание металла |
| CMT | Cold Metal Transfer — перенос с холодным переносом капель | вариант WAAM с малым тепловложением, меньше разбрызгивания |
| Межслойная проковка | удар/обжатие каждого слоя до наложения следующего | измельчение зерна, снижение остаточных напряжений, закрытие пор |
| ЗТВ | зона термического влияния | зона структурных изменений вокруг наплавленного металла |

### Физика, которая здесь работает

1. Межслойная проковка действительно измельчает зерно — это подтверждённый эффект, и он же
   обосновывает исходный пункт гипотезы о «микропоковке».
2. Защитная атмосфера нужна именно при наплавке и диффузионной сварке: в дуговых процессах металл
   переносится через расплав, и без газа он насыщается кислородом и азотом.
3. Резкое охлаждение «для мелкого зерна» для 40ХН2МА неприменимо: получается неотпущенный
   мартенсит — хрупкость и холодные трещины. Мелкое зерно даёт деформация и рекристаллизация,
   а структуру всё равно задаёт финишная закалка с высоким отпуском.

### Почему это не основной путь для гибкого колеса

| Ограничение | Механизм | Следствие |
|---|---|---|
| Усталость | гибкое колесо циклически изгибается; наплавленный металл по выносливости уступает деформированному | прямое попадание в главный критерий — ресурс |
| Пористость | газовая пористость между слоями, несплавления | концентраторы → очаги усталостных трещин |
| Точность | стенка 0.88 мм, припуск на финишную обработку съедает половину допуска | нужен припуск ≥ 1 мм, а его негде взять |
| Коробление | градиенты при наплавке на тонкой оболочке | некруглость, с которой потом борется правка |
| Габарит | 70…160 мм с тонкой стенкой — невыгодный диапазон для WAAM | экономика хуже, чем у раскатки |

### Разумная роль

Наращивание **массивных** элементов на толстую заготовку: фланец крепления, бурт, прилив под
подшипник. То есть WAAM не заменяет раскатку, а дополняет её там, где нужен локальный массивный
объём, который иначе снимался бы за многие часы точения.

Схема: труба или раскатанный стакан → WAAM/CMT наращивает фланец → полная термообработка
(закалка + высокий отпуск) → мехобработка. Наплавленный металл никогда не остаётся в зоне
циклического изгиба: он уходит либо в стружку, либо в толстую часть.

### Процесс (ориентировочно, подлежит проверке)

| Параметр | Ориентир | Комментарий |
|---|---|---|
| Проволока | 40ХН2МА-св или близкая по составу; альтернатива — 30ХГСА-св | легирование проволоки должно быть не ниже основы, иначе шов мягче |
| Защитный газ | Ar + 2…5 % CO₂ (для CMT), расход 12…18 л/мин | защита от окисления и азотирования |
| Ток / напряжение | 100…180 А / 12…18 В (CMT, короткая дуга) | малое тепловложение — меньше коробления |
| Температура подложки | предподогрев 150…200 °C, межслойная ≤ 250 °C | снижает градиент, но не даёт отпуск мартенсита «сам собой» |
| Шаг слоя | 1.5…2.5 мм | согласуется с толщиной валика |
| Проковка | каждый слой, 5…15 кДж удара/обжатие, до наложения следующего | цель — зерно и снятие напряжений |
| Термообработка после | закалка 870 °C масло + отпуск 580 °C | те же режимы, что для 40ХН2МА (Д-112) |
| Припуск на мехобработку | ≥ 1.5 мм на сторону | снять ЗТВ и дефектный поверхностный слой |

### Что нужно проверить (эксперимент)

| Ступень | Образец | Критерий |
|---|---|---|
| 1 | стенка-пластина 10×40×60 мм на подложке 40ХН2МА, проковка по слоям | пористость ≤ 1 % по шлифу, нет несплавлений |
| 2 | цилиндр Ø70, стенка 6 мм, наращивание фланца | овальность ≤ 0.1 мм, коробление ≤ 0.3 мм |
| 3 | образцы на усталость (изгиб при кручении), сравнение с основным металлом | σ₋₁ наплавленного ≥ 0.9·σ₋₁ деформированного |

Критерий 3 — решающий: если выносливость ниже 90 % основы, ветка закрывается для гибкого колеса
и остаётся только для неподвижных фланцев.

### Что это не решает

WAAM не избавляет от проблемы соединений сам по себе: он заменяет одно соединение (кольцо + штифты)
на другое (наплавка на подложку с ЗТВ). Там, где можно получить монолит раскаткой, раскатка
дешевле и по прочности лучше. Поэтому TECH-04 — ветка для массивных элементов, а TECH-03 — целевой
маршрут заготовки.
