## CP-109 — C-1: собственный член ряда делится пополам (P1, меняет формулы)

**Что:** в `_sep` момент в центре узла для промежуточного пояса:

```python
# было
mb = [(V[j] + V[j + 1]) * (L + h) / 4 + m_r + F * h / 4 for j in range(rows - 1)]
# станет
mb = [(V[j] + V[j + 1]) * (L + h) / 4 + (m_r + F * h / 4) / 2 for j in range(rows - 1)]
```

**Почему:** перенос `F/2` на плечо `h/2` верен, но у неразрезной балки с равными пролётами
симметричный член на промежуточную опору не передаётся — моменты `F·L/12` и пары `F/2` с плечами
`±h/2` от верхней и нижней перемычек взаимно уничтожаются. Неуравновешенный момент возникает,
только когда нагружена одна перемычка, и тогда делится на два пояса. `s_end` **не меняется** —
у торца перемычка одна, момент полный, деление на 2 уже есть.

**Проверка:** `s_bd` 70.98 → **60.44**, `τ` 29.04 → **24.73** (self-test), `183F75` 61.38 → 54.11,
`1EDF34` 4.47 → 3.69.

**Влияние на прогон:** ноль на текущих данных (нет строк с `lim_elem = «пояс»`). Если после
правки такие строки появятся — M может вырасти до +15…20 %, проверить в SPEC-10.

## CP-111 — косметика `_sep` и глоссарий (P2, на M не влияет)

1. `sig_core` считается всегда по глубине перемычки `b`; при `lim_elem` = пояс/торец глубина своя
   (`h_mid`, `h_end`) — писать по элементу `lim_elem` и без приведения `s_max·allow/al`.
2. Срез пояса сравнивается с `0.58·allow` перемычки; правильно — `0.58·al` пояса. У 40Х совпадает,
   у `nitr` нет.
3. Глоссарий (`ptk_doc`): «`u_st` > 1 — не отказ». При u = 10 перемычка 32 мм против окна 8 мм,
   сепаратор работает как оболочка с отверстиями: момент идёт сдвиговым потоком, а не изгибом
   консоли. Схема «полоса-консоль» неверна по механизму, а не консервативна.
4. Self-test: при `M_by == «сепаратор»` — `|max(u_b, u_H) − 1| < 1e-3`.

## CP-112 — `K_δ` через `sep_r_corner` и верное обоснование (P2, ждёт МКЭ)

**Модель признала своё обоснование неверным:** концентрация от радиуса `r` затухает на глубине
порядка `r`, поэтому при `δ` = 0.4 > `r` = 0.3 к границе слоя она почти исчезла. Оценка по Киршу,
масштабированная на `K` = 2: `K_δ ≈ 1 + (K − 1)·(r/(r+δ))² ≈ 1.18`.

| Случай | `[σ]` при `K_δ = 2` | `[σ]` при `K_δ ≈ 1.18` |
|---|---|---|
| R6X6, b = 5.894 | 90.7 (ядро) | 121.6 (слой), **+34 %** |
| K20, b = 3.015 | 106.7 (ядро) | 121.6 (слой), +14 % |
| u = 32/1000, b = 8.243 | 86.8 | 121.6 → M ≈ 1034 ≥ 1000 |

**Действия:** значение `K_δ = 2` оставить до МКЭ; исправить текст Д-126 и INS-10 §7.1 (заменить
«при r ≲ δ концентрация не затухает» на обратное); ввести параметр `sep_r_corner` для OQ-44;
пометить вывод TECH-01 и INS-10 §7.2 «изгиб материалом не двигается» как **условный** — он верен
только при `K_δ = K`, при затухании азотирование даёт +14…34 % по изгибу.

## CP-113 — TECH-01: четыре дополнения к азотированию (P2, текст)

1. **Кромки окон:** острая кромка при азотировании пересыщается с двух сторон и выкрашивается —
   скругление или фаска **R ≥ 0.3 мм до азотирования** (тот же радиус, что входит в `K`, OQ-44).
2. **Обезуглероживание:** само азотирование (520–560 °C) не обезуглероживает; слой остаётся от
   закалки при 940 °C. Его снять механообработкой до азотирования, иначе слой формируется плохо.
   Практический вывод: окна режутся **после улучшения, до азотирования**.
3. **ЭЭС (Т3, OQ-11):** переплавленный слой с микротрещинами снять чистовым проходом.
4. **Рост размеров:** на поверхность прирастает несколько мкм — припуск на ширину окна задавать
   с учётом роста.

## Что не меняем (подтверждено моделью)

- Пересчёт семи референсных строк **не нужен**: ни в одной пояс не задаёт предел.
- Перенос через ряды **не завышен**: `sig_row/sig_b` = 0.16 стабильно, `n·R·k_sep` = 4.000 —
  следствие того, что Σsin² по нагруженной половине равна `n/4`.
- `k_case` = 3 оставить: запас 17–44× к `z_τ`, значение нечувствительно.
- `u_H = 1.000` — не артефакт: обе загрузки линейны по `M`, при `M_by = сепаратор` максимум
  равен 1 по определению; разница 533.274 против 533.333 — округление `M` до 0.1.
