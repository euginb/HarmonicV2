# GIGACODE.md — HarmonicV2 (EG-MACHINES)

## Обзор проекта

**HarmonicV2** — проект промышленного станкостроения и робототехники **EG-MACHINES**.
Основная цель: разработка ячейки мелкосерийного производства волновых редукторов
диаметром ≤110 мм для изготовления станков на эпоксигранитных станинах
(фрезерный SM-1, электроэрозионная SE-1; компоновки HMC/VMC).

**Приоритеты:** точность → дешевизна → скорость.

Проект использует гибридный подход:
- **Spec-first** — технология, методики, договорённости правятся напрямую в `specs/`
- **Code-first** — числа живут в коде (`egm/`) и конфигах (`specs/*.yaml`), результат — прогон `python main.py`

## Запуск и проверка

```bash
# Полный прогон (калькулятор + проработка + проверки + каталог)
python main.py all

# Только шаг 1: расчёт ПТК (SPEC-10 → ptk_configs.json)
python main.py calc

# Только шаг 2: проработка (SPEC-11 → ptk_designs.json) по опубликованному шагу 1
python main.py design

# Прогон + копирование в репозиторий (reports всегда, specs — только при OK)
python main.py --publish

# Генерация чертежей SVG/STEP по ID
python -m egm.cad <ID>[.<NN><вар>]

# Комплект чертежей по спецификации
python -m egm.cad --spec specs/cad_set.yaml

# Код выхода 0 — все проверки пройдены
```

**Зависимости:** стандартная библиотека Python. Для CAD (cadquery, FreeCAD) —
устанавливаются отдельно. Для YAML: `pip install pyyaml`.

## Взаимодействие с ИИ

Проект использует **Super Agent** с зеркалированием в AI Drive (песочница):
- GitHub — первоисточник; зеркало `/HarmonicV2-main.zip` — рабочая копия

- Прямые правки через токен GitHub — режим INS-91 §8

Полная таблица признаков → разделов инструкции — в `README.md` (раздел «Когда открывать instructions/README.md») и `instructions/README.md` §1.

## Важные технические детали

### Волновой редуктор ПТК
- 4 ряда (0°/90°/180°/270°), Øнар ≤110 мм, передаточное u = 10…100
- u = n = z − 1 (n — тел в ряду, z — впадин венца)
- Типы генератора: `bearing` (на наружном кольце подшипника) / `eccentric` (на эксцентрике)
- Шаги расчёта: 1) калькулятор SPEC-10 → ptk_configs.json; 2) проработка SPEC-11 → ptk_designs.json

### Конструктивы сепаратора (Д-73)
- **L1** — стакан монолитом (.02A)
- **L2** — обечайка с буртом + ступица (.02B + .12A, collar)
- **L3** — обечайка без бурта + дно-вставка (.02C + .12B, insert)
- **L4** — обечайка + кольцо-бурт + дно-лист + ступица (.14)

### Патчи
- Формат: `# base: <sha>, CP-##`, UTF-8 LF
- Пред наложением: `python tools/fix_diff.py p.diff` → `git apply --check`
- Имена файлов: `CP-##_<name>_base<7sha>.diff`

## Правила оформления коммитов

Формат сообщения коммита:

```
[<имя-брана>] <сообщение>
```

- **`<имя-брана>`** — имя текущей ветки, в которой делается коммит (например `rev-11.4`, `rev-11.3`).
- Запись в квадратных скобках — префикс, отделяется пробелом от сообщения.
- Сообщение — краткое описание изменений, по смыслу как в коммитах `b3340295` / `dffe105`.
- Пример: `[rev-11.4] Добавил в .gitignore служебные файлы GigaCode`

Правило действует для всех коммитов в проекте.
