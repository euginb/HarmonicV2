# INS-10 — Калькулятор ПТК: параметры и чтение результата

Спецификация: `specs/SPEC-10_PTK_CALC.md` (таблица), `specs/ptk_configs.json` (те же
данные для кода). Код: `egm/ptk.py`, профиль — `egm/ptk_profile.py`. Решения: Д-08,
Д-11, Д-16, Д-18, Д-19, Д-22, Д-31, Д-33.

## Что считает

Для каждого u из `limits.u_list`, каждого тела качения из
`vendor_prices.json` → `rollers` и каждого крепления из `ring_mounts` строится
одноступенчатый редуктор и проверяется,
помещается ли он в Øнар max вместе с крепёжными отверстиями венца. Расчёт идёт от
центра наружу:

```
z            = u + 1,  n = u                      Д-31: венец неподвижен, выход — сепаратор
e            = min(ecc_k · Ø тела, e_margin · e max)   e max — без подреза профиля
Ø генератора = Ø дел. − Ø тела − 2e              ≥ gen_bore_min
Ø дел.       = n · gap_k · Ø тела / π            окружность центров тел
Ø впадин     = Ø дел. + Ø тела + 2e              профиль венца
Ø окр. отв.  = Ø впадин + 2a                     центры отверстий
Øнар         = Ø окр. отв. + 2a                  ≤ d_out_max
a = max(wall_min + d_clear/2, dk/2 + head_margin)
```

Здесь a — расстояние от профиля впадин до оси отверстия, столько же — от оси до
наружной кромки. Оно зависит только от выбранного болта: чем крупнее болт, тем
толще венец и тем меньше места остаётся телам.

Профиль венца — волнистый, между двумя окружностями: Ø вершин = Ø дел. + Ø тела − 2e
(выступы внутрь) и Ø впадин = Ø дел. + Ø тела + 2e; глубина волны 2e. Как строится
траектория тела, откуда e max и почему волна мелкая — раздел «Профиль венца и
глубина волны».

Какие строки попадают в таблицу при нескольких креплениях — `mount_mode`
(раздел `ring_mounts` ниже).

## Файл `specs/ptk_input.json`

### `ring_mounts` — набор креплений венца (Д-16, Д-33)

`ring_mounts` — словарь `{ключ: крепление}`; поля одного крепления — таблица ниже.
Каждая пара (u, тело) считается со всеми креплениями в порядке записи:

| `mount_mode` | Что попадает в SPEC-10 |
|---|---|
| `first_ok` (по умолчанию) | первое крепление, прошедшее все проверки; если не прошло ни одно — первое по списку, с его ошибками |
| `all` | все крепления, по строке на каждое |

Порядок записей — приоритет: первым ставится основное крепление (крупнее болт,
больше M крепл.), за ним — запасные для тесных случаев (M3, меньше отверстий).
Ключ (`M4x8P2`) — только имя: стоит в скобках в колонке «Отверстия» и в поле
`mount`, в ID не входит; состав отверстий входит в ID (`8M4P2`) и в хэш (Д-22).
Порядок симметрии сверловки N у креплений разный, поэтому число вариантов венца
(Д-19) зависит от крепления. Без штифтов (`pins = 0`) угловую фазу ряда держать
нечем — такое крепление ставить только для проверки.

```
"mount_mode": "first_ok",
"ring_mounts": {
  "M4x8P2": {"bolt": "M4", "n": 8, "pins": 2, "pin_d": 4.0, ...},
  "M3x8P2": {"bolt": "M3", "n": 8, "pins": 2, "pin_d": 3.0, ...}
}
```

Старый формат — один блок `ring_holes` — читается как единственное крепление с
ключом `default`; в рабочем `ptk_input.json` его не использовать.

Одни и те же отверстия крепят редуктор в машине и базируют венец на оснастке
станков при изготовлении (ЭЭС, фрезерование). Число отверстий любое (Д-19):
отверстия пакета сквозные и совпадают, а фаза ряда получается поворотом сверловки
каждого венца относительно его профиля (раздел «Фазировка» ниже). Штифтовые
отверстия H7 задают угловое положение детали на оснастке и в машине.

| Параметр | Ед. | Смысл | Проверка |
|---|---|---|---|
| `bolt` | — | резьба болта, ключ таблицы `fasteners` (M3…M8) | нет в таблице → ошибка |
| `n` | шт | число крепёжных отверстий, любое; болт j на угле j·360°/n | помещаются по шагу |
| `pins` | шт | число штифтовых отверстий посередине промежутков j = round(i·n/pins) (промежуток j — между болтами j и j+1); 0 — без штифтов | помещаются между головками; влияют на симметрию N |
| `pin_d` | мм | Ø штифта | — |
| `head_margin` | мм | зазор от головки болта до впадин и до наружной кромки | входит в a |
| `web_min` | мм | минимальная перемычка между соседними головками или головкой и штифтом | шаг отверстий |
| `mu` | — | коэффициент трения в стыке венец/корпус (сталь по стали, сухо: 0.1…0.15) | момент удержания |
| `safety` | — | требуемый запас: M крепл. ≥ safety · M | иначе предупреждение |

Шаг отверстий (хорда) = Ø окр. отв. · sin(180°/n); он должен быть не меньше
`dk + web_min` и не меньше `d_clear + wall_min`.

Момент удержания: M крепл. = n · F_M · mu · D_отв/2 — момент, который стык передаёт
трением от затяжки болтов (штифты не учитываются). Допускаемый момент (Д-41):
M = min(M_H по Герцу, M_B по C0 подшипника, M крепл./safety); в SPEC-10 в скобках —
что ограничивает. Ошибка — только M < `M_min`.

### `fasteners` — таблица крепежа

| Поле | Ед. | Смысл | Источник |
|---|---|---|---|
| `d_clear` | мм | Ø отверстия под болт | ISO 273, средний ряд |
| `dk` | мм | Ø головки винта с цилиндрической головкой | ISO 4762 |
| `F_M` | кН | сила затяжки | ориентировочно, кл. 8.8, μ резьбы 0.12 (VDI 2230) |

Значения надо сверить с вашим справочником. Новый размер добавляется строкой,
например `"M10": {"d_clear": 11.0, "dk": 16.0, "F_M": 27.0}`.

## Подшипник генератора: `specs/vendor_prices.json` → `bearings` (Д-40)

Тела катятся по наружному кольцу подшипника, внутреннее кольцо сидит на эксцентрике.
Поля: `d`, `D`, `B` — мм, `C`, `C0` — кН. Калькулятор берёт наименьший D ≥ 2R_Σ min − D_ш
с d ≥ `shaft_d_min` + 2(a_ω + `ecc_wall_min`); R_Σ = (D + D_ш)/2, D_г = D. Шаг ряда —
max(l тела, B подшипника) + `row_gap`. Нет подходящего — ошибка «нет подшипника».

## Тела качения: `specs/vendor_prices.json` → `rollers`

| Поле | Смысл |
|---|---|
| ключ (`ROLLER_D5x8`) | обозначение тела, по нему же ищется цена в `items` |
| `type` | `roller` — ролик, `ball` — шарик |
| `d` | Ø тела, мм |
| `l` | длина ролика, мм (для шарика = Ø) — определяет ширину ряда |

## Фазировка рядов и сдвиг сверловки (Д-19)

Ряд k — копия ряда 1, повёрнутая на φk (эксцентрик генератора). Отверстия пакета
сквозные, в корпусе они на одних и тех же углах. Значит, поворот переносится на
сверловку: каждый венец сверлится со своим сдвигом относительно профиля.

```
p = 360/z                 шаг впадин
N                         порядок симметрии сверловки (болты + штифты)
g = 360 / НОК(z, N)       шаг, по модулю которого сдвиги неразличимы
s_k = (−φk) mod g         поворот сверловки ряда k от впадины 0, град
s_k·π·Ø окр.отв./360      то же по дуге, мм (ptk_configs.json → s_arc_mm)
φk mod (360/n)            смещение гнёзд ряда k в сепараторе
```

Венцы с одинаковым s — одна деталь. Все 4 венца одинаковы, если z кратно 4 или N
кратно 4. Примеры для 8 болтов:

| Штифты | N | Венцов при z = 20 | при z = 63 |
|---|---|---|---|
| 0 | 8 | 1 | 1 |
| 2 (напротив) | 2 | 1 | 2 |
| 4 (через 90°) | 4 | 1 | 1 |
| 1 или 3 | 1 | 1 | 4 |

Несимметричные штифты исключают неверную установку венца, но увеличивают число
вариантов и управляющих программ.

Допущение: фаза — угол поворота эксцентрика ряда. Если фаза задаётся иначе
(общий эксцентрик, поворот профиля на долю шага), формула другая — сообщить
исполнителю.

## Профиль венца и глубина волны (Д-31)

Вывод формул — SPEC-10, раздел «Профиль венца и кинематика» (текст генерирует
`egm/ptk_profile.py`). Здесь — что из них следует для выбора параметров.

```
R0 = Ø дел./2,  ρ = Ø тела/2,  t — угол от впадины 0 в системе венца
r(t) = e·cos(z·t) + √(R0² − e²·sin²(z·t))       траектория центра тела
профиль венца = эквидистанта r(t) наружу на ρ
e max ≈ (R0 − e)·(1 + (R0 − e)/ρ) / z²          вершина без подреза; точно — численно
```

Тело в радиальном пазу сепаратора ходит на 2e; длина паза ≥ Ø тела + 2e.
Подстановка R0 = n·gap_k·Ø тела/(2π) и n ≈ z даёт оценку, в которой u сокращается:

```
e max / Ø тела ≈ gap_k² / (2π²)
2e / Ø тела    ≈ e_margin · gap_k² / π²
```

Глубина волны — доля Ø тела, почти одинаковая для всех u. Это предел подреза, а не
погрешность построения: кривизна траектории на вершине растёт как e·z², и при
большем e эквидистанта на ρ петляет. Оценка для u = 63, ролик Ø2, 8×M4
(первая строка — PTK-063-R2X4_2-8M4P2-E8CE81 из SPEC-10, остальные — по формулам,
точные значения — прогоном):

| gap_k | e max / Ø | 2e / Ø при e_margin 0.8 | 2e, мм | Ø дел. | Øнар |
|---|---|---|---|---|---|
| 1.15 | 0.068 | 0.108 | 0.22 | 46.1 | 73.3 |
| 1.5 | 0.114 | 0.18 | 0.37 | 60.2 | ≈ 87.5 |
| 2.0 | 0.20 | 0.32 | 0.64 | 80.2 | ≈ 108 |

Что из этого следует:

1. Глубже волну делает `gap_k`; `e_margin` → 0.9 даёт только +12 %, `ecc_k`
   при gap_k < 2.5 не действует.
2. `gap_k` общий для всех u: рост помогает малым u (растёт Ø генератора) и
   глубине волны, но увеличивает Øнар — большие u (80, 100) уходят за `d_out_max`.
3. Предупреждение «глубина волны < 5 % Ø тела» срабатывает только при
   gap_k < 0.8; мелкую волну при обычных gap_k оно не ловит — смотрите колонку e
   и сравнивайте 2e с точностью изготовления профиля (ЭЭС).
4. e max зависит от ρ: при одном Ø дел. тело крупнее даёт волну мельче.

## Маркировка конфигураций (Д-22)

Каждая строка результата получает ID исполнения — по нему генерируются 2D/3D
чертежи (CP-05), он же стоит на чертеже и детали.

```
PTK-063-R5X8-8M4P2-3F9A1C
│   │   │    │     └ хэш (6 hex) параметров геометрии
│   │   │    └ отверстия венца: 8×M4 + 2 штифта (без штифтов — 8M4)
│   │   └ тело: R<Ø>X<L> — ролик, B<Ø> — шарик; дробь через «_»: 2_5
│   └ u, 3 цифры
└ тип редуктора (SPEC-01)
```

Хэш считается от `ptk_configs.json → geom`: `GEOM_REV`, u, тело (type, d, l),
`limits.gap_k, ecc_k, e_margin, wall_min, row_gap, rows, row_phases`,
поля крепления `bolt, n, pins, pin_d, head_margin`, `fasteners.<bolt>.d_clear, dk`.
Правка любого из них даёт новый ID; правка `mu`, `safety`, `F_M`, `d_out_max`,
`gen_bore_min`, `web_min`, `u_list`, ключа крепления и `mount_mode` ID не меняет.
`4` и `4.0` равнозначны. Смена формул геометрии повышает `GEOM_REV` в
`egm/ptk.py` — меняются все ID (Д-31: GEOM_REV = 2).

Детали исполнения — `<ID>.<NN>[вариант]`, список — `parts[]`:

| NN | Деталь | Статус |
|---|---|---|
| 01A, 01B… | венец, вариант сверловки (раздел «Фазировка»), ряды — `parts[].rows` | генерируется |
| 02… | сепаратор, генератор, тела, шайбы, корпус | OQ-04 |

Найти запись по ID исполнения или детали — `ptk.find(rows, id)`.

## Как читать результат

Сначала смотрите столбец «Статус». Если стоит «нет», причина указана в разделе
«Нереализуемые конфигурации». Столбец «Ø тела max» показывает, какое тело влезло
бы при данном u: если он меньше Ø тела, возьмите тело мельче или болт меньше.
В скобках в колонке «Отверстия» — ключ выбранного крепления из `ring_mounts`.

Малые u ограничивает не крепление, а Ø генератора:
Ø генератора ≈ Ø тела · (n·gap_k/π − 1) − 2e ≥ `gen_bore_min`. При gap_k = 1.15 и
gen_bore_min = 18 нужно тело не меньше ≈ 6.8 мм для u = 10, 3.7 для u = 16, 2.85
для u = 20, 2.2 для u = 25. Если в ошибках строки есть «генератор … мал», запасные
крепления её не спасут — нужно тело крупнее (`bodies`), больше `gap_k` или
меньше `gen_bore_min`.

Типовые правки:

| Нужно | Что менять |
|---|---|
| проверить болт M5 вместо M4 | запись `"M5x8P2": {"bolt": "M5", …}` в `ring_mounts`; первой — чтобы стала основной |
| 12 отверстий вместо 8 | запись с `"n": 12` в `ring_mounts` |
| видеть все крепления, а не первое прошедшее | `mount_mode = "all"` |
| глубже волна профиля | больше `limits.gap_k` (раздел «Профиль венца и глубина волны») |
| пройти малые u | тело крупнее в `bodies`; см. «Малые u ограничивает…» выше |
| добавить ролик Ø3×5 | новая запись в `vendor_prices.json` → `bodies` и `items` |
| таблица только для u = 30…60 | `limits.u_list = [30, 40, 50, 60]` |
