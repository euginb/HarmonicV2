# INS-10 — Калькулятор ПТК: параметры и чтение результата

Спецификация: `specs/SPEC-10_PTK_CALC.md` (таблица), `specs/ptk_configs.json` (те же
данные для кода). Код: `egm/ptk.py`. Решения: Д-08, Д-11, Д-16, Д-18.

## Что считает

Для каждого u из `limits.u_list` и каждого тела качения из
`vendor_prices.json` → `bodies` строится одноступенчатый редуктор и проверяется,
помещается ли он в Øнар max вместе с крепёжными отверстиями венца. Расчёт идёт от
центра наружу:

```
Ø генератора = Ø дел. − Ø тела − 2e              ≥ gen_bore_min
Ø дел.       = n · gap_k · Ø тела / π            окружность центров тел
Ø впадин     = Ø дел. + Ø тела + 2e              профиль венца
Ø окр. отв.  = Ø впадин + 2a                     центры отверстий
Øнар         = Ø окр. отв. + 2a                  ≤ d_out_max
a = max(wall_min + d_clear/2, dk/2 + head_margin)
```

Здесь a — расстояние от профиля впадин до оси отверстия, столько же — от оси до
наружной кромки. Оно зависит только от выбранного болта: чем крупнее болт, тем
толще венец и тем меньше места остаётся телам.

## Файл `specs/ptk_input.json`

### `limits` — геометрия и диапазон

| Параметр | Ед. | Смысл | Как влияет |
|---|---|---|---|
| `d_out_max` | мм | наибольший наружный Ø редуктора (Д-08: 110) | главный габаритный предел |
| `u_min`, `u_max` | — | диапазон одноступенчатого u (Д-08: 10…100) | u > u_max → рекомендация двух ступеней (Д-11) |
| `wall_min` | мм | минимальная стенка венца: между впадинами и отверстием, отверстием и наружной кромкой | больше → толще венец |
| `gap_k` | — | шаг тел по окружности, делённый на Ø тела; 1.15 = перемычка сепаратора 15 % от Ø тела | больше → прочнее сепаратор, больше Ø дел. |
| `ecc_k` | — | эксцентриситет, делённый на Ø тела (e = ecc_k · Ø тела) | предварительно 0.25; уточняется в CP-08 |
| `gen_bore_min` | мм | наименьший Ø генератора, в который помещаются подшипник и вал | ограничивает малые u |
| `row_gap` | мм | осевой зазор или шайба между рядами | входит в ширину B |
| `rows` | шт | число рядов тел (Д-08: 4) | — |
| `row_phases` | град | фазы эксцентриков генератора по рядам (Д-08: 0, 90, 180, 270); длина списка должна равняться `rows` | проверяется; задаёт сдвиг сверловки венцов (Д-19) |
| `u_list` | — | какие u считать в таблице | только состав таблицы |

### `ring_holes` — крепёжные / технологические отверстия венца (Д-16)

Одни и те же отверстия крепят редуктор в машине и базируют венец на оснастке
станков при изготовлении (ЭЭС, фрезерование). Число отверстий любое (Д-19):
отверстия пакета сквозные и совпадают, а фаза ряда получается поворотом сверловки
каждого венца относительно его профиля (раздел «Фазировка» ниже). Штифтовые
отверстия H7 задают угловое положение детали на оснастке и в машине.

| Параметр | Ед. | Смысл | Проверка |
|---|---|---|---|
| `bolt` | — | резьба болта, ключ таблицы `fasteners` (M3…M8) | нет в таблице → ошибка |
| `n` | шт | число крепёжных отверстий, любое; болт j на угле j·360°/n | помещаются по шагу |
| `pins` | шт | число штифтовых отверстий посередине промежутков j = round(i·n/pins) (промежуток j — между болтами j и j+1); 0 — без штифтов | помещаются между головками; влияют на симметрию N |
| `pin_d` | мм | Ø штифта | — |
| `head_margin` | мм | зазор от головки болта до впадин и до наружной кромки | входит в a |
| `web_min` | мм | минимальная перемычка между соседними головками или головкой и штифтом | шаг отверстий |
| `mu` | — | коэффициент трения в стыке венец/корпус (сталь по стали, сухо: 0.1…0.15) | момент удержания |
| `safety` | — | требуемый запас: M крепл. ≥ safety · M | иначе предупреждение |

Шаг отверстий (хорда) = Ø окр. отв. · sin(180°/n); он должен быть не меньше
`dk + web_min` и не меньше `d_clear + wall_min`.

Момент удержания: M крепл. = n · F_M · mu · Ø окр. отв./2. Это момент, который
стык передаёт трением от затяжки болтов. Пока M — заглушка (CP-08), поэтому
несоблюдение запаса выдаётся как **предупреждение**, а не ошибка.

### `fasteners` — таблица крепежа

| Поле | Ед. | Смысл | Источник |
|---|---|---|---|
| `d_clear` | мм | Ø отверстия под болт | ISO 273, средний ряд |
| `dk` | мм | Ø головки винта с цилиндрической головкой | ISO 4762 |
| `F_M` | кН | сила затяжки | ориентировочно, кл. 8.8, μ резьбы 0.12 (VDI 2230) |

Значения надо сверить с вашим справочником. Новый размер добавляется строкой,
например `"M10": {"d_clear": 11.0, "dk": 16.0, "F_M": 27.0}`.

## Тела качения: `specs/vendor_prices.json` → `bodies`

| Поле | Смысл |
|---|---|
| ключ (`ROLLER_D5x8`) | обозначение тела, по нему же ищется цена в `items` |
| `type` | `roller` — ролик, `ball` — шарик |
| `d` | Ø тела, мм |

## Фазировка рядов и сдвиг сверловки (Д-19)

Ряд k — копия ряда 1, повёрнутая на φk (эксцентрик генератора). Отверстия пакета
сквозные, в корпусе они на одних и тех же углах. Значит, поворот переносится на
сверловку: каждый венец сверлится со своим сдвигом относительно профиля.

```
p = 360/z                 шаг впадин
N                         порядок симметрии сверловки (болты + штифты)
g = 360 / НОК(z, N)       шаг, по модулю которого сдвиги неразличимы
s_k = (−φk) mod g         поворот сверловки ряда k от впадины 0, град
s_k·π·Ø окр.отв./360      то же по дуге, мм (ptk_configs.json → s_arc_mm)
φk mod (360/n)            смещение гнёзд ряда k в сепараторе
```

Венцы с одинаковым s — одна деталь. Все 4 венца одинаковы, если z кратно 4 или N
кратно 4. Примеры для 8 болтов:

| Штифты | N | Венцов при z = 20 | при z = 63 |
|---|---|---|---|
| 0 | 8 | 1 | 1 |
| 2 (напротив) | 2 | 1 | 2 |
| 4 (через 90°) | 4 | 1 | 1 |
| 1 или 3 | 1 | 1 | 4 |

Несимметричные штифты исключают неверную установку венца, но увеличивают число
вариантов и управляющих программ.

Допущение: фаза — угол поворота эксцентрика ряда. Если фаза задаётся иначе
(общий эксцентрик, поворот профиля на долю шага), формула другая — сообщить
исполнителю.

## Маркировка конфигураций (Д-22)

Каждая строка результата получает ID исполнения — по нему генерируются 2D/3D
чертежи (CP-05), он же стоит на чертеже и детали.

```
PTK-063-R5X8-8M4P2-3F9A1C
│   │   │    │     └ хэш (6 hex) параметров геометрии
│   │   │    └ отверстия венца: 8×M4 + 2 штифта (без штифтов — 8M4)
│   │   └ тело: R<Ø>X<L> — ролик, B<Ø> — шарик; дробь через «_»: 2_5
│   └ u, 3 цифры
└ тип редуктора (SPEC-01)
```

Хэш считается от `ptk_configs.json → geom`: `GEOM_REV`, u, тело (type, d, l),
`limits.gap_k, ecc_k, wall_min, row_gap, rows, row_phases`,
`ring_holes.bolt, n, pins, pin_d, head_margin`, `fasteners.<bolt>.d_clear, dk`.
Правка любого из них даёт новый ID; правка `mu`, `safety`, `F_M`, `d_out_max`,
`gen_bore_min`, `web_min`, `u_list` ID не меняет. `4` и `4.0` равнозначны.

Детали исполнения — `<ID>.<NN>[вариант]`, список — `parts[]`:

| NN | Деталь | Статус |
|---|---|---|
| 01A, 01B… | венец, вариант сверловки (раздел «Фазировка»), ряды — `parts[].rows` | генерируется |
| 02… | сепаратор, генератор, тела, шайбы, корпус | OQ-04 |

Найти запись по ID исполнения или детали — `ptk.find(rows, id)`.

## Как читать результат

Сначала смотрите столбец «Статус». Если стоит «нет», причина указана в разделе
«Нереализуемые конфигурации». Столбец «Ø тела max» показывает, какое тело влезло
бы при данном u: если он меньше Ø тела, возьмите тело мельче или болт меньше.

Типовые правки:

| Нужно | Что менять |
|---|---|
| проверить болт M5 вместо M4 | `ring_holes.bolt = "M5"` |
| 12 отверстий вместо 8 | `ring_holes.n = 12` |
| без штифтов | `ring_holes.pins = 0` |
| добавить ролик Ø3×5 | новая запись в `vendor_prices.json` → `bodies` и `items` |
| таблица только для u = 30…60 | `limits.u_list = [30, 40, 50, 60]` |
