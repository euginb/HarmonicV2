# INS-10 — Калькулятор ПТК: параметры и чтение результата

Спецификация: `specs/SPEC-10_PTK_CALC.md` (таблица), `specs/ptk_configs.json` (те же
данные для кода). Код: `egm/ptk.py` (подбор, ID), `egm/ptk_profile.py` (профиль, траектория
(6) Янгулова), `egm/ptk_force.py` (силы, Герц, момент). Решения: Д-08, Д-11, Д-16, Д-18,
Д-19, Д-22, Д-31, Д-33, Д-35, Д-37, Д-38, Д-40…Д-43, Д-45.

## Что считает

Для каждого u из `limits.u_list`, каждого тела из `vendor_prices.json → rollers`,
каждого типа генератора из `limits.gen_types` и каждого крепления из `ring_mounts`
строится одноступенчатый редуктор: геометрия, профиль венца, допускаемый выходной
момент M, проверка D. Расчёт идёт от центра наружу (обозначения — колонки SPEC-10):

```
z = u + 1,  n = u                          Д-31, Д-38: венец неподвижен, выход — сепаратор
aω    = a_k · Dш  (или a_w тела)           эксцентриситет генератора
RΣ min — наибольшее из условий             подрез, сепаратор, вал; колонка R_by (Д-38)
Dг    = D подшипника (bearing, Д-40) | Ø эксцентрика (eccentric, Д-42)
RΣ    = (Dг + Dш)/2                        окружность центров тел генератора
DВ    = 2(RΣ + aω) + Dш                    диаметр впадин венца
Dверш = 2(RΣ − aω) + Dш                    диаметр вершин
Dотв  = DВ + 2c     вверх до d_bc_step     окружность центров отверстий (Д-35)
D     = Dотв + 2c   вверх до d_out_step    наружный диаметр, ≤ d_out_max (Д-43)
c     = max(wall_min + d_clear/2, dk/2 + head_margin)
M     = min(M_H, M_B, M крепл./safety)     Д-41; в скобках в SPEC-10 — ограничитель
```

c — расстояние от впадин до оси отверстия и от оси до наружной кромки; зависит только
от болта. Чем крупнее болт, тем больше D при тех же телах.

Какие строки попадают в таблицу при нескольких креплениях — `mount_mode` (ниже).

## Файл `specs/ptk_input.json`

### `limits` — геометрия, материалы, диапазон

| Параметр | Ед. | Смысл | Как влияет |
|---|---|---|---|
| `d_out_max` | мм | наибольший D: 110 — станки и оснастка EG-MACHINES (Д-08); `null` — без предела (Д-43) | D > d_out_max — ошибка; `Dш max` считается только при заданном пределе |
| `u_min`, `u_max` | — | диапазон одноступенчатого u (Д-08: 10…100) | u > u_max → две ступени (Д-11) |
| `u_list` | — | какие u считать | только состав таблицы |
| `a_k` | — | aω / Dш, если у тела не задан `a_w` (Д-38: 0.2) | больше → глубже волна и больше α max, но больше RΣ по подрезу |
| `r_tip_min` | мм | наименьший радиус кривизны профиля на вершине (подрез) | задаёт RΣ min при больших u |
| `sep_web_min` | мм | наименьшая перемычка сепаратора между гнёздами | задаёт RΣ min при малых u |
| `wall_min` | мм | стенка венца: впадины — отверстие — кромка; у тела можно переопределить | больше → больше D |
| `shaft_d_min` | мм | Ø входного вала в эксцентрике (Д-40) | с `ecc_wall_min` — нижний предел d подшипника и Dг эксцентрика |
| `ecc_wall_min` | мм | стенка эксцентрика: d ≥ shaft_d_min + 2(aω + ecc_wall_min) | больше → крупнее генератор при малых u |
| `gen_types` | — | типы генератора (Д-42): `bearing` — тела на наружном кольце подшипника; `eccentric` — прямо по эксцентрику | каждая пара (u, тело) считается для каждого типа; тип — в хэше ID и в колонке «Генератор» |
| `dgen_step` | мм | округление вверх Dг эксцентрика | только `eccentric` |
| `groove_f` | — | радиус жёлоба под шарик на эксцентрике / Dш, > 0.5 (Д-45, Т2); 0.52 — как у шарикоподшипников | меньше → выше допускаемая сила шарик/эксцентрик; в ID не входит |
| `d_bc_step`, `d_out_step` | мм | округление вверх Dотв и D (Д-35) | проверка `d_out_max` — после округления |
| `E_mod`, `nu` | МПа, — | упругость тел, венца, колец (сталь: 210000, 0.3) | Герц (Д-41) |
| `sigma_H_line`, `sigma_H_point` | МПа | допускаемое контактное напряжение: ролик (линия) / шарик (точка) | ниже → меньше M_H; калибровка — OQ-08 |
| `s0_brg` | — | запас C0/P0 подшипника генератора | больше → меньше M_B |
| `M_min` | Н·м | требуемый M; 0 — не проверяется | M < M_min — ошибка |
| `row_gap` | мм | осевой зазор или шайба между рядами | входит в B |
| `rows`, `row_phases` | шт, град | число рядов (Д-08: 4) и фазы эксцентриков (0, 90, 180, 270); длина списка = `rows` | сдвиг сверловки венцов (Д-19) |

Прежние параметры `gap_k*`, `ecc_k`, `e_margin`, `gen_bore_min`, `Dgen_min` не
используются: RΣ определяется условиями выше (Д-38, Д-40).

### `ring_mounts` — набор креплений венца (Д-16, Д-33)

`ring_mounts` — словарь `{ключ: крепление}`. Каждая тройка (u, тело, генератор)
считается со всеми креплениями в порядке записи:

| `mount_mode` | Что попадает в SPEC-10 |
|---|---|
| `first_ok` (по умолчанию) | первое крепление, прошедшее все проверки; если ни одно — первое по списку, с его ошибками |
| `all` | все крепления, по строке на каждое |

Порядок записей — приоритет: первым — основное (крупнее болт, больше M крепл.), за ним —
запасные для тесных случаев. Ключ (`M4x8P2`) — только имя: стоит в скобках в колонке
«Отверстия» и в поле `mount`, в ID не входит; состав отверстий входит (`8M4P2`).
Без штифтов (`pins = 0`) угловую фазу ряда держать нечем — только для проверки.

Одни и те же отверстия крепят редуктор в машине и базируют венец на оснастке станков
(ЭЭС, фрезерование); штифты H7 задают угловое положение.

| Параметр | Ед. | Смысл | Проверка |
|---|---|---|---|
| `bolt` | — | резьба, ключ таблицы `fasteners` | нет в таблице → ошибка |
| `n` | шт | число болтов; болт j на угле j·360°/n | помещаются по шагу |
| `pins` | шт | штифты посередине промежутков j = round(i·n/pins); 0 — без штифтов | влияют на симметрию N (Д-19) |
| `pin_d` | мм | Ø штифта | — |
| `head_margin` | мм | зазор от головки до впадин и до кромки | входит в c |
| `web_min` | мм | перемычка между головками или головкой и штифтом | шаг отверстий |
| `mu` | — | трение в стыке венец/корпус (сталь, сухо: 0.1…0.15) | M крепл. |
| `safety` | — | запас: M ≤ M крепл./safety | ограничивает M (Д-41) |

Шаг (хорда) = Dотв · sin(180°/n) ≥ max(dk + web_min, d_clear + wall_min).
M крепл. = n · F_M · mu · Dотв/2 — момент, передаваемый трением стыка (штифты не учитываются).

### `fasteners` — таблица крепежа

| Поле | Ед. | Смысл | Источник |
|---|---|---|---|
| `d_clear` | мм | Ø отверстия под болт | ISO 273, средний ряд |
| `dk` | мм | Ø головки винта с цилиндрической головкой | ISO 4762 |
| `F_M` | кН | сила затяжки | ориентировочно, кл. 8.8, μ резьбы 0.12 (VDI 2230) |

Значения сверить со справочником. Новый размер добавляется строкой, например
`"M10": {"d_clear": 11.0, "dk": 16.0, "F_M": 27.0}`.

## Покупные позиции: `specs/vendor_prices.json`

`rollers` — тела качения: ключ (`R_D3x8`, `B_D3`) — обозначение, по нему же цена в
`items`; `type` — `roller` | `ball`; `d` — Ø, мм; `l` — длина ролика (у шарика = Ø), мм;
необязательные `a_w`, `wall_min` переопределяют `limits` для этого тела.

`bearings` — подшипники генератора (Д-40): `d`, `D`, `B` — мм, `C`, `C0` — кН.
Тела катятся по наружному кольцу, внутреннее сидит на эксцентрике. Берётся наименьший
D ≥ 2RΣ min − Dш с d ≥ shaft_d_min + 2(aω + ecc_wall_min); Dг = D. Шаг ряда —
max(l тела, B подшипника) + `row_gap`. Нет подходящего — ошибка «нет подшипника
генератора». C, C0 серии 618 сверить с каталогом поставщика (OQ-09).

## Генератор и технологические коды (Д-42, Д-45)

| Код | Когда | Что значит для пользователя |
|---|---|---|
| Т1 | шарик + `bearing` | исполнение исключено: на кольце покупного подшипника жёлоб не сделать; строка — в разделе «Исключённые по технологии» SPEC-10, `egm.cad` выводит причину |
| Т2 | шарик + `eccentric` | контакт с эксцентриком считается по жёлобу `groove_f`; жёлоб — на чертёж .03 |
| Т3 | шарик + `eccentric` | в венце жёлоба нет, обычно эта пара ограничивает M (B_D3, u = 10: ≈ 1 Н·м); жёлоб в венце — OQ-11 |
| Т4 | любое тело + `eccentric` | скольжение тело/эксцентрик ≈ ω·Dг/2; предел скорости входа не проверяется (OQ-10) |

Коды стоят в колонке «Статус» («OK (Т4)»); полная расшифровка — в конце SPEC-10.
Ролик с `bearing` кодов не получает.

## Фазировка рядов и сдвиг сверловки (Д-19)

Ряд k — копия ряда 1, повёрнутая на φk (эксцентрик генератора). Отверстия пакета
сквозные, в корпусе они на одних и тех же углах. Значит, поворот переносится на
сверловку: каждый венец сверлится со своим сдвигом относительно профиля.

```
p = 360/z                 шаг впадин
N                         порядок симметрии сверловки (болты + штифты)
g = 360 / НОК(z, N)       шаг, по модулю которого сдвиги неразличимы
s_k = (−φk) mod g         поворот сверловки ряда k от впадины 0, град
s_k·π·Dотв/360            то же по дуге, мм (ptk_configs.json → s_arc_mm)
φk mod (360/n)            смещение гнёзд ряда k в сепараторе
```

Венцы с одинаковым s — одна деталь. Все 4 венца одинаковы, если z кратно 4 или N
кратно 4. Примеры для 8 болтов:

| Штифты | N | Венцов при z = 20 | при z = 63 |
|---|---|---|---|
| 0 | 8 | 1 | 1 |
| 2 (напротив) | 2 | 1 | 2 |
| 4 (через 90°) | 4 | 1 | 1 |
| 1 или 3 | 1 | 1 | 4 |

Несимметричные штифты исключают неверную установку венца, но увеличивают число
вариантов и управляющих программ.

Допущение: фаза — угол поворота эксцентрика ряда. Если фаза задаётся иначе (общий эксцентрик, поворот профиля на долю шага), формула другая — сообщить исполнителю.

## Профиль венца (Д-38)

Вывод формул — SPEC-10, разделы о профиле и силовом расчёте (текст генерируют
`egm/ptk_profile.py`, `egm/ptk_force.py`). Следствия для выбора параметров:

1. Профиль — эквидистанта траектории центра тела (6) Янгулова на Dш/2; глубина волны
   DВ − Dверш = 4aω, то есть задаётся `a_k` и не зависит от u.
2. Угол передачи α max ≈ arctg √(2aω/Dш): при `a_k` = 0.2 около 32°. Меньший угол —
   больше радиальная сила на тело при том же M.
3. При больших u RΣ ограничивает подрез (`r_tip_min`): кривизна траектории на вершине
   растёт как aω·z², RΣ и D растут почти пропорционально u — u = 80, 100 выходят за `d_out_max`.
4. При малых u RΣ задают сепаратор (`sep_web_min`), вал или подшипник генератора;
   `R_by` в `ptk_configs.json` (на чертеже — «RΣ задан») показывает, какое условие сработало.

## Маркировка конфигураций (Д-22)

Каждая строка результата получает ID исполнения — по нему генерируются чертежи
(`python -m egm.cad`, INS-30), он же стоит на чертеже и детали.

```
PTK-063-R2X4_2-8M3P2-BE3303
│   │   │      │     └ хэш (6 hex) параметров геометрии
│   │   │      └ отверстия венца: 8×M3 + 2 штифта (без штифтов — 8M3)
│   │   └ тело: R<Ø>X<L> — ролик, B<Ø> — шарик; дробь через «_»: 4_2
│   └ u, 3 цифры
└ тип редуктора (SPEC-01)
```

Хэш — от `ptk_configs.json → geom`: `GEOM_REV`, u, тело (`GEOM_ROLLER`), параметры
`limits` из `GEOM_LIMITS`, крепление (`GEOM_HOLES`), `fasteners.<bolt>.d_clear, dk`,
подшипник (`GEOM_BEARING`) и тип генератора — перечни в `egm/ptk.py`. Правка любого из
них даёт новый ID; `mu`, `safety`, `F_M`, `web_min`, `u_list`, материалы, `sigma_H_*`,
`groove_f`, ключ крепления и `mount_mode` ID не меняют; `4` и `4.0` равнозначны. Смена
формул геометрии повышает `GEOM_REV` — меняются все ID (сейчас GEOM_REV = 6).

Детали исполнения — `<ID>.<NN>[вариант]`, список — `parts[]`:

| NN | Деталь | Статус |
|---|---|---|
| 01A, 01B… | венец, вариант сверловки (раздел «Фазировка»), ряды — `parts[].rows` | генерируется |
| 02… | сепаратор, генератор, тела, шайбы, корпус | OQ-04 |

Найти запись по ID исполнения или детали — `ptk.find(rows, id)`.

## Как читать результат

Сначала смотрите «Статус». «нет» — причина в разделе «Нереализуемые конфигурации»;
коды Т# — раздел «Генератор и технологические коды»; исключённые (Т1) — отдельным
списком в конце SPEC-10. «Dш max» — какое тело поместилось бы при данном u.
«M» — допускаемый выходной момент, в скобках — что его ограничивает: «контакт» — Герц
(M_H), «подшипник» — C0 подшипника генератора (M_B), «крепление» — M крепл./safety.

Типовые правки:

| Нужно | Что менять |
|---|---|
| проверить болт M5 вместо M4 | запись `"M5x8P2": {"bolt": "M5", …}` в `ring_mounts`, первой — чтобы стала основной |
| 12 отверстий вместо 8 | запись с `"n": 12` в `ring_mounts` |
| видеть все крепления, а не первое прошедшее | `mount_mode = "all"` |
| M ограничивает «крепление» | больше болтов или крупнее болт в `ring_mounts`; `mu`, `safety` — по данным испытаний |
| M ограничивает «подшипник» | подшипник с большим C0 в `bearings` или тело крупнее |
| глубже волна, больше α max | больше `limits.a_k` (растёт RΣ по подрезу и D) |
| считать только с подшипником | `limits.gen_types = ["bearing"]` |
| добавить ролик Ø3×5 | запись в `vendor_prices.json` → `rollers` и `items` |
| таблица только для u = 30…60 | `limits.u_list = [30, 40, 50, 60]` |
