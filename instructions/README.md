# INS-00 — Инструкции к code-first спецификациям и глоссарий (Д-17)

Code-first спецификация — результат прогона `main.py`, руками она не правится.
Чтобы изменить результат, меняют **входные файлы** и запускают прогон заново.
Инструкция описывает, какие входные файлы есть, что означает каждый параметр
и как читать результат. Номер инструкции совпадает с номером спецификации.

| Инструкция | Спецификация / БД | Входные файлы |
|---|---|---|
| [INS-10_PTK_CALC.md](INS-10_PTK_CALC.md) | `specs/SPEC-10_PTK_CALC.md`, `specs/ptk_configs.json` | `specs/ptk_input.json`, `specs/vendor_prices.json` → `bodies` |
| [INS-20_CATALOG.md](INS-20_CATALOG.md) | `specs/catalog_hiwin_hg.json`, `specs/catalog_hiwin_hg_pairs.json`, `reports/catalog_report.md` | `docs/HG-Series-Catalog_opt.md`, `specs/vendor_prices.json` |

## Порядок работы

1. Правите входной файл (`specs/*_input.json`, `specs/vendor_prices.json`).
2. `python main.py` — результат в `out/specs/` и `out/reports/`.
3. Смотрите `out/reports/checks.md`: «все пройдены» = код выхода 0.
4. Переносите результат: вручную или `python main.py --publish` (Д-14).
5. Коммит.

В JSON ключи, начинающиеся с `_` (`_comment`), — комментарии, код их пропускает.
Неизвестный параметр (опечатка в имени) — ошибка прогона, а не молчаливое игнорирование.

## Глоссарий проекта

| Сокращение | Расшифровка |
|---|---|
| ПТК | волновой редуктор с промежуточными телами качения (ролики/шарики) |
| ГК | волновой редуктор с гибким колесом (классический harmonic drive) |
| ЭЭС | электроэрозионная система, прошивочный электроэрозионный станок |
| ЭХП | электрохимическое полирование — снятие перелитого слоя после ЭЭС (Д-05) |
| HMC / VMC | горизонтальная / вертикальная компоновка станка (`docs/cnc_axes_guide.md`, Д-09) |
| SM / SE | станок фрезерный (milling) / электроэрозионный (erosion) — SPEC-01 |
| K1 / K2 / K3 | классы точности закладных: базовые / силовые / вспомогательные — SPEC-02 |
| M1 … M4 | способы монтажа закладных в литьё — SPEC-02 |
| Д-## | принятое решение (`specs/DECISIONS.md`) |
| OQ-## | открытый вопрос (`specs/DECISIONS.md`) |
| CP-## | пункт плана доработки кода (`specs/CODE_PLAN.md`), в коде — `TODO(CP-##)` |
| X-## | отменённое положение (`specs/CANCELLED.md`) |
| CAT-## | каталог производителя в реестре `specs/CATALOGS.md` |
| EGC | префикс нашего каталожного номера покупной позиции (EG-machines Component, Д-10) |
| SPEC-## / INS-## | спецификация / инструкция к ней |

## Обозначения волнового редуктора ПТК

| Обозначение | Смысл |
|---|---|
| u | передаточное число |
| z | число впадин жёсткого колеса (внешнего венца) |
| n | число тел качения в ряду, n = z − 1 |
| e | эксцентриситет генератора волн |
| Ø дел. | делительный диаметр — окружность центров тел |
| венец | внешнее жёсткое колесо с профилем впадин; неподвижно, крепится к корпусу/машине |
| сепаратор | кольцо с гнёздами тел; выходное звено |
| генератор волн | эксцентрик (кулачок) с подшипником; входное звено |
| ряд | один слой тел по оси; рядов 4, фазы 0/90/180/270° (Д-08) |
