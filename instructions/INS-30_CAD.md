# INS-30 — генератор чертежей 2D/3D по ID (CP-20, CP-24)

Связанные решения: Д-22 (ID исполнения), Д-24 (номенклатура), Д-30 (2D и 3D
из одной геометрии). Код — `egm/cad/`, данные — `specs/ptk_configs.json`
(code-first, результат калькулятора) и `specs/products.json` (spec-first,
номенклатура, SPEC-03).

## 1. Сокращения

| Сокращение | Расшифровка |
|---|---|
| ПТК | волновой редуктор с промежуточными телами качения |
| ID исполнения | `PTK-<u>-<тело>-<отверстия>-<хэш6>` — маркировка конфигурации калькулятора (Д-22) |
| ID детали | `<ID исполнения>.<NN>[<вариант>]` (SPEC-03) |
| NN | двузначный номер позиции номенклатуры изделия в `products.json` |
| вариант | буква A, B… — исполнения одной позиции; у венца — разный сдвиг сверловки s (Д-19) |
| u, z | передаточное число; число впадин венца, z = u + 1 (Д-31) |
| n | число крепёжных отверстий венца |
| s | сдвиг сверловки венца от впадины 0, град (Д-19) |
| STEP | 3D-модель (ISO 10303): FreeCAD, КОМПАС-3D, SolidWorks |
| SVG | 2D-чертёж с размерами, масштаб 1:1, мм: браузер, Inkscape |
| CadQuery | Python-библиотека 3D-моделирования, нужна только для STEP |

## 2. Подготовка

1. `python main.py --publish` с кодом выхода 0: генератор читает только
   опубликованный `specs/ptk_configs.json`, он должен соответствовать текущему
   коду и `specs/ptk_input.json`.
2. Для STEP — `pip install cadquery`. Без него строится только SVG, в выводе
   «step: пропущен».

## 3. Запуск

| Команда | Что строится |
|---|---|
| `python -m egm.cad <ID исполнения>` | все детали исполнения, у которых есть генератор |
| `python -m egm.cad <ID детали>` | одна деталь, например `PTK-020-R5X8-8M4P2-00124C.01A` |
| `python -m egm.cad <ID1> <ID2> …` | несколько аргументов по очереди |
| `python -m egm.cad <ID> --phase 90` | венец ряда с фазой φ = 90° (`row_phases`), на чертеже — направление его эксцентрика; файл `<NN><вар>-r<k>.svg` |
| `python -m egm.cad <ID> --row 2` | то же по номеру ряда |
| `python -m egm.cad <ID> --assy` | сборка исполнения одним STEP `<ID>.step`: дерево ROWk → детали, слои 01_RING…REF, цвета, метаданные; дубль дерева, метаданных и предлагаемые виды — `<ID>.assy.json` (Д-49, OQ-14) |

ID исполнения — колонка ID в SPEC-10 или `ptk_configs.json → id`; ID деталей,
их сдвиги s и ряды — `ptk_configs.json → parts[]`.
Коды выхода: 0 — построено; 1 — ID не найден, нет генератора или ошибка
геометрии; 2 — нет аргументов.

## 4. Результат

`out/cad/<ID исполнения>/<NN><вариант>.svg` и `.step`. Папка `out/` в git не
хранится: чертёж воспроизводится командой по ID.

Венец `.01`: наружный контур, контур впадин (дуги, Д-30), окружность центров
гнёзд и окружность отверстий (штрихпунктир), крепёжные отверстия и штифты H7
со сдвигом s; размеры Øнар, Ø окр. отв., Ø впадин, Ø центров гнёзд; в шапке —
ID, крепёж, z, s, толщина, ряды пакета, в которых стоит этот вариант.

«предупреждение: … нереализуема: …» — конфигурация не прошла проверки SPEC-10
(причина в тексте), чертёж строится только для анализа. ID не найден —
изменилась геометрия (новый хэш, Д-22), новый ID — в SPEC-10.

## 5. Номенклатура и состав по умолчанию

Номенклатура — `specs/products.json → <изделие>.parts.<NN>`, поля — SPEC-03.
Две позиции ПТК приняты по умолчанию; меняется правкой JSON и прогоном
`python main.py`:

| Позиция | По умолчанию | Альтернатива — что вписать |
|---|---|---|
| `PTK.parts."02"` сепаратор | одна деталь на пакет: `"variant": "none", "qty": 1` | по ряду: `"variant": "row", "qty": "rows"` (детали `.02A…D`) |
| `PTK.parts."03"` генератор | эксцентрик на ряд: `"variant": "row", "qty": "rows"` | единый вал: `"name": "вал генератора", "variant": "none", "qty": 1` |

Пока калькулятор формирует в `parts[]` только венцы `.01`, поэтому эта правка
меняет номенклатуру и проверку `products.check`; на чертежи она повлияет с
появлением генераторов `.02/.03`. Номера `.NN` не переиспользуются, новая
позиция — в конец.

## 6. Новый генератор детали

1. `egm/cad/<имя>.py`: `build(cfg, part, row) -> PartModel` (`egm/cad/model.py`)
   и `self_test()`; рендеры `svg.render` и `step.export` общие для всех деталей (Д-32).
   Размеры и легенда подписываются обозначениями колонок SPEC-10.
2. Регистрация в `egm/cad/__main__.py → GENERATORS`, self_test — в `main.py`.
3. `"cad": "<имя>"` у позиции в `products.json`.

## 7. Ограничения

Профиль впадин — эквидистанта траектории центра тела по (6) Янгулова (Д-38,
GEOM_REV = 4), 24 точки на шаг впадин (`ptk_profile.profile_points`, k = 24).
В SVG — ломаная по этим точкам. В STEP (CP-29) деталь строится одной гранью и одним
выдавливанием, без булевых операций: наружная окружность D, контур впадин, окружности
отверстий. Контур впадин в STEP — `--step spline` (по умолчанию): периодический B-сплайн
через точки профиля, одна гладкая боковая грань; `--step poly` — ломаная, z·k плоских
граней (если сплайн не строится или невалиден); `--step off` — только SVG.
В 2D пока только вид по оси; изометрия и разрезы — проекциями из STEP (CP-06).
