# INS-90 — AUDIT_BUNDLE.md: создание и использование для review

Тип: инструкция  
Статус: черновик  
Источник: порядок работы с ИИ и review репозитория без прямого доступа к GitHub

## 1. Назначение

`AUDIT_BUNDLE.md` — это снимок текущего состояния репозитория в текстовом виде,
предназначенный для review ИИ, когда ИИ не имеет прямого доступа к GitHub.

Bundle не заменяет репозиторий и не является первоисточником проекта.
Первоисточник — Git-репозиторий на указанном commit SHA.

Способ — резервный: применяется, когда недоступны одновременно GitHub
(способы Д-12, Д-15) и AI Drive (Д-20, элемент инфраструктуры Genspark).
Если доступен хотя бы один из них — используется доступный способ.

## 2. Когда используется

`AUDIT_BUNDLE.md` используется, если:

1. ИИ не может прочитать GitHub напрямую.
2. Нужно зафиксировать контекст review на конкретном commit SHA.
3. Нужно передать ИИ структуру репозитория и содержимое текстовых файлов одним файлом.
4. Нужно исключить анализ истории коммитов и проверить только текущее состояние.
5. GitHub и AI Drive (Д-20, элемент инфраструктуры genspark.ai) недоступны
   одновременно — условие применения способа (Д-21); при доступности любого
   из них используются Д-12/Д-15 или Д-20.

## 3. Базовые требования к bundle

В начале `AUDIT_BUNDLE.md` обязательно указываются:

1. Название bundle.
2. Commit SHA, от которого сделан снимок.
3. Полный список файлов репозитория.
4. Содержимое текстовых файлов, пригодных для review.
