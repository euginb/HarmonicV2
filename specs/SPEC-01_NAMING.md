# SPEC-01 — Маркировка станков и узлов (spec-first, Д-02, Д-09)

## Станки: `S<T><N>-<L>`

| Поз. | Значение |
|---|---|
| S | станок |
| T | тип: M — milling (фрезерный); E — erosion (прошивочный электроэрозионный) |
| N | порядковый номер варианта данного типа (1, 2, …) |
| L | компоновка по `docs/cnc_axes_guide.md`: VMC — вертикальный шпиндель/электрод (Z вертикальна); HMC — горизонтальный (Y вертикальна) |

Номер N — вариант конструкции; компоновка L — суффикс того же варианта.
SM-1-HMC и SM-1-VMC — одна машина SM-1 в двух компоновках, они рассчитываются
параллельно и сравниваются (Д-09). Основная компоновка — HMC.

| Код | Описание | Статус |
|---|---|---|
| SM-1-HMC | фрезерный, вариант 1, горизонтальный (меньше нагрузка на ось Z) | основной |
| SE-1-HMC | ЭЭС, вариант 1, горизонтальный (в ванну погружается только рабочая часть) | основной |
| SM-1-VMC | фрезерный, вариант 1, вертикальный | для сравнения |
| SE-1-VMC | ЭЭС, вариант 1, вертикальный | для сравнения |

Код станка входит во все производные имена, поэтому файлы вариантов HMC и
VMC не конфликтуют:

| Объект | Имя |
|---|---|
| спецификация станка | `specs/machines/<код>.md` |
| дерево узлов (JSON) | `specs/machines/<код>.json` |
| 3D/2D модели | `out/cad/<код>/…` |
| ID узла | `<код>.<группа>.<NN>[.<NN>]` |

Правила разбора кода и список станков — `egm/naming.py` (`naming.MACHINES`).

## Узлы и детали: `<станок>.<группа>.<NN>[.<NN>]`

Группы: FR — станина (литьё), EM — закладные, AX — оси (AX-X, AX-Y, AX-Z, AX-C),
SP — шпиндель/электрододержатель, TK — ванна ЭЭС, FX — оснастка, AC — навесное.
Пример: `SE-1-HMC.AX-X.02` — каретка оси X. Номер совпадает с ключом в JSON-дереве.

Покупные изделия — каталожным номером из `specs/catalog_*.json` (Д-10),
детали редукторов — `PTK-<исп>.<NN>[<вариант>]` и `HD-<исп>.<NN>`. Исполнение ПТК —
ID конфигурации `PTK-<u>-<тело>-<отверстия>-<хэш>` (Д-22, INS-10), напр.
`PTK-063-R5X8-8M4P2-3F9A1C.01B` — венец варианта B.
