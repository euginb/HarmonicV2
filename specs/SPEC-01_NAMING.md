# SPEC-01 — Маркировка станков и узлов (spec-first, Д-02)

## Станки: `S<T><N>-<L>`

| Поз. | Значение |
|---|---|
| S | станок |
| T | тип: M — milling (фрезерный); E — erosion (прошивочный электроэрозионный) |
| N | порядковый номер варианта данного типа (1, 2, …) |
| L | компоновка по `docs/cnc_axes_guide.md`: VMC — вертикальный шпиндель/электрод (Z вертикальна); HMC — горизонтальный (Y вертикальна) |

Примеры: SM-1-VMC — фрезерный, вариант 1, вертикальный; SE-1-VMC —
электроэрозионный, вариант 1, вертикальный. Смена компоновки даёт новый
номер варианта (SM-2-HMC), старый не переименовывается.

## Узлы и детали: `<станок>.<группа>.<NN>[.<NN>]`

Группы: FR — станина (литьё), EM — закладные, AX — оси (AX-X, AX-Y, AX-Z, AX-C),
SP — шпиндель/электрододержатель, TK — ванна ЭЭС, FX — оснастка, AC — навесное.
Пример: `SE-1-VMC.AX-X.02` — каретка оси X. Номер совпадает с ключом в JSON-дереве.

Покупные изделия — каталожным номером из `specs/catalog_*.json` (OQ-03),
детали редукторов — `PTK-<исп>.<NN>` и `HD-<исп>.<NN>`.
