# SPEC-03 — Изделия и номенклатура деталей (spec-first, Д-24)

Данные — `specs/products.json`, правятся напрямую. Код (`egm/products.py`)
проверяет, что каждая деталь из `specs/ptk_configs.json → parts[]` есть в
номенклатуре своего изделия.

## Обозначение

`<ID исполнения>.<NN>[<вариант>]`, ID исполнения — Д-22, NN — номер позиции
номенклатуры (две цифры), вариант — буква (A, B…), если позиция вариантная.
Пример: `PTK-063-R5X8-8M4P2-3F9A1C.01B` — венец варианта B.

## Поля позиции

| Поле | Значения | Смысл |
|---|---|---|
| `name` | текст | наименование детали |
| `kind` | `make` / `buy` | изготавливаемая / покупная |
| `variant` | `none` / `ring_phase` / `row` | без вариантов; по сдвигу сверловки (Д-19); по ряду (A…D) |
| `qty` | число или выражение из `rows`, `n_bodies` | количество на изделие |
| `cad` | имя генератора или `null` | `python -m egm.cad <ID>.<NN>` строит STEP/SVG |

## Состояние ПТК

Генератор есть у `.01` (венец). Сепаратор `.02` — одна деталь на пакет,
эксцентрик `.03` — по ряду (принято по умолчанию, меняется в products.json).
Новая позиция добавляется в конец, номера не переиспользуются.
