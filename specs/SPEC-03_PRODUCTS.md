# SPEC-03 — Изделия и номенклатура деталей (spec-first, Д-80)

Данные — `specs/products.yaml` (YAML, Д-79), правятся напрямую. Код (`egm/products.py`)
проверяет, что каждая деталь из `specs/ptk_configs.json → parts[]` есть в
номенклатуре своего изделия.

## Обозначение

`<ID исполнения>.<NN>[<вариант>]`, ID исполнения — Д-80, NN — номер позиции
номенклатуры (две цифры), вариант — буква (A, B…), если позиция вариантная; что
различает буквы каждой позиции — INS-30 §5 (таблица «Варианты деталей») и INS-10 §6.6 (Д-63).
Пример: `PTK-063-R5X8-8M4P2-3F9A1C.01B` — венец варианта B.

## Поля позиции

| Поле | Значения | Смысл |
|---|---|---|
| `name` | текст | наименование детали |
| `kind` | `make` / `buy` | изготавливаемая / покупная |
| `variant` | `none` / `ring_phase` / `row` / `layout` / `thick` / `side` | без вариантов; по сдвигу сверловки s (Д-19); по ряду — паз шпонки на угле ряда (Д-46); по конструктиву — A стакан / B обечайка (Д-54); по толщине — A торцы / B между рядами (Д-53); по стороне — A вход / B выход (Д-54); расшифровка — INS-30 §5 |
| `qty` | число или выражение из `rows`, `n_bodies` | количество на изделие |
| `cad` | имя генератора или `null` | `python -m egm.cad <ID>.<NN>` строит STEP/SVG |

## Состояние ПТК

Генераторы чертежей: `.01`, `.02`, `.03`, `.05`, `.07`, `.11` (поле `cad`). Две
позиции приняты по умолчанию, обе меняются правкой `specs/products.yaml → PTK.parts`
(INS-30 §8):
сепаратор `.02` — одна деталь на пакет (`"variant": "none", "qty": 1`;
по ряду — `"row"`, `"rows"`); генератор `.03` — эксцентрик на каждый ряд
(`"variant": "row", "qty": "rows"`; единый вал — `"none"`, `1`).
Новая позиция добавляется в конец, номера не переиспользуются.
