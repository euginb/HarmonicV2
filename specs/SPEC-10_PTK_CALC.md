### Расшифровка колонок

| Колонка | Поле в ptk_configs.json | Ед. | Смысл |
|---|---|---|---|
| ID | `id` | — | маркировка исполнения (Д-22): `PTK-<u>-<тело>-<отверстия>-<хэш геометрии>`; по нему генерируются 2D/3D. Детали — `parts[]`: `<ID>.01A`… венцы; снимок параметров — `geom` |
| u | `u` | — | передаточное число: вход — генератор волн, выход — сепаратор |
| Тело | `body` | — | ключ тела качения из `vendor_prices.json` → `bodies` |
| Ø тела | `d_body` | мм | диаметр ролика или шарика |
| Ø тела max | `d_body_max` | мм | наибольший Ø тела, при котором редуктор с данным u и текущими отверстиями ещё вписывается в Øнар max |
| n тел | `n_bodies` | шт | число тел в одном ряду, n = z − 1 |
| z | `z_ring` | шт | число впадин жёсткого колеса (внешнего венца), z = u + 1 (Д-31) |
| e | `ecc` | мм | эксцентриситет генератора волн, e = min(ecc_k · Ø тела, e_margin · e max); e max (`e_max`) — предел подреза, раздел «Профиль венца»; Ø вершин — `d_tip` |
| Ø дел. | `d_pitch` | мм | делительный диаметр — окружность центров тел, n · gap_k · Ø тела / π |
| Ø впадин | `d_root` | мм | наружный диаметр профиля впадин венца, Ø дел. + Ø тела + 2e |
| Отверстия | `holes`, `mount` | — | крепёжные (они же технологические) отверстия венца: число × резьба + штифты; в скобках — ключ крепления `ring_mounts` (Д-33) |
| Вар. венца | `ring_variants` | шт | число разных сверловок венца в пакете рядов (Д-19): 1 — все венцы одинаковы; сдвиги — в разделе «Фазировка рядов», по каждой конфигурации — `phasing` |
| Ø окр. отв. | `d_bc` | мм | диаметр окружности центров отверстий |
| Øнар | `d_out` | мм | наружный диаметр венца = габарит редуктора |
| B | `width` | мм | осевая ширина пакета тел: ряды × длина тела + зазоры |
| M | `torque_Nm_est` | Н·м | оценка допустимого выходного момента (заглушка до CP-08) |
| M крепл. | `t_hold` | Н·м | момент, удерживаемый трением в стыке от затяжки болтов венца |
| Статус | `ok` | — | OK — все проверки пройдены; нет — причина в разделе ниже |

## Профиль венца и кинематика (Д-31, CP-08)

Схема Д-11: венец неподвижен, вход — эксцентрик генератора, выход — сепаратор с
радиальными пазами; тело в пазу движется строго по радиусу и прижато к эксцентрику.

| Обозначение | Смысл |
|---|---|
| R0 | Ø дел./2 = радиус наружного кольца эксцентрика + ρ |
| ρ | Ø тела/2 |
| e | эксцентриситет генератора |
| φ, ψ | углы поворота эксцентрика (вход) и сепаратора (выход) |
| t | угол в системе венца от впадины 0 |

Расстояние центра тела от оси: ρc = e·cos(α − φ) + √(R0² − e²·sin²(α − φ)),
α — угол тела. Профиль венца с z впадинами r(α) = F(z·α) держит контакт со всеми
телами при любом φ, если z·α ≡ α − φ для каждого тела, отсюда:

- n = z − 1, ψ = −φ/n, **u = n = z − 1** (вращение обратное); для заданного u
  калькулятор берёт z = u + 1 (u = z — схема с неподвижным сепаратором и выходом
  на венец, X-06);
- траектория центра тела в системе венца: **r(t) = e·cos(z·t) + √(R0² − e²·sin²(z·t))**;
- профиль венца — эквидистанта траектории наружу на ρ;
  Ø впадин = 2(R0 + e + ρ), Ø вершин = 2(R0 − e + ρ), глубина волны 2e;
- ход тела в пазу сепаратора 2e, длина паза ≥ Ø тела + 2e;
- подрез: на вершинах (выступах внутрь) радиус кривизны траектории
  ρк = (r² + r′²)^{3/2} / |r² + 2r′² − r·r″| должен быть ≥ ρ. На вершине
  r″ = e·z²(1 − e/R0), откуда **e max ≈ (R0 − e)(1 + (R0 − e)/ρ) / z²**;
  точное значение — численно (`egm/ptk_profile.py: e_max`);
- принято **e = min(ecc_k·Ø тела, e_margin·e max)**.

Контакт Герца и момент — CP-08, открыто.
