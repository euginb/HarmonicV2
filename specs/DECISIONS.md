# DECISIONS — журнал решений и открытые вопросы

Решения нумеруются `Д-##` общие для проекта, либо `Д-##.####` относящееся к конкретному станку, группируются по типам и не переписываются: при отмене решение помечается как
отменённое со ссылкой на заменившее. Открытые вопросы — `OQ-##`, закрытые
остаются в списке с пометкой и ссылкой на решение.

## Принятые решения

| №    | Решение | Ревизия |
|------|---|---------|
| Д-01 | Порядок работ: исполнитель готовит патчи по плану CODE_PLAN.md (пункты CP-## дублируются `TODO(CP-##)` в коде); заказчик запускает `main.py` и докладывает результат; пункт закрывается только после прогона | rev 0   |
| Д-02 | Маркировка станков `S<тип><№>-<компоновка>` по SPEC-01 | rev 0   |
| Д-03 | Классы точности закладных K1/K2/K3 и способы монтажа M1–M4 по SPEC-02 | rev 0   |
| Д-04 | Закладные — лазерный раскрой из 2–3 листов; жёсткость рёбрами/прокатом; под рельсы — сегменты с зазором 10 мм | rev 0   |
| Д-05 | Основное формообразование — ЭЭС, фрезерование вспомогательное; перелитой слой снимается ЭХП | rev 0   |
| Д-06 | Полярная схема обработки: контур круглых деталей по X+C, без контурного хода по Y | rev 0   |
| Д-07 | Данные производителей только из `specs/*.json`; компоновка узлов — относительными правилами, не абсолютными координатами | rev 0   |
| Д-08 | Редуктор ПТК: 4 ряда, фазировка 0°/90°/180°/270°, Øнар ≤110, u = 10…100 | rev 0   |
