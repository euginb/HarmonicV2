# DECISIONS — журнал решений и открытые вопросы

Решения нумеруются `Д-##` общие для проекта, либо `Д-##.####` относящееся к конкретному станку, группируются по типам и не переписываются: при отмене решение помечается как
отменённое со ссылкой на заменившее. Открытые вопросы — `OQ-##`, закрытые
остаются в списке с пометкой и ссылкой на решение.

Свёртка 2026-10 (Д-77, CP-68…CP-71): группировка — по типу продукта (общее /
машины / ПТК; будущие продукты получают свои кластеры) и темам; кластеры решений — сводные секции Д-78…Д-90 (2026-10-24 группы продуктов преобразованы в кластеры Д-85…Д-90) (принципы списком, ключи
в пунктах). Секции — шапки: состав и суть; полные тексты и кластерная разбивка
— в [archive/DECISIONS-2026-10.md](archive/DECISIONS-2026-10.md). Ссылки на членов кластеров по репозиторию заменены на сводные;
ключи резолвятся (context_bundle ищет подстроку по всему дереву, включая
архив).

#### Д-87 — ПТК — кинематика и расчёт

Действующий набор принципов (тексты и разбивка членов — в [archive/DECISIONS-2026-10.md](archive/DECISIONS-2026-10.md)):

- Д-08: редуктор ПТК: 4 ряда, фазировка 0°/90°/180°/270°, Øнар ≤110, u = 10…100.
- Д-11: схема ПТК: жёсткое колесо неподвижно, выход на сепаратор, n = z − 1, u = z; одноступенчатый расчёт — только u = 10…100; для u > 100 калькулятор не считает и рекомендует двухступенчатую схему u = u1·u2.
- Д-19: число отверстий венца ПТК — любое; фаза ряда φk (Д-08) — поворот эксцентрика генератора; каждый венец сверлится со своим сдвигом s_k = (−φk) mod g, g = 360°/НОК(z, N), N — порядок симметрии сверловки (болты + штифты); равные s — один вариант венца; гнёзда сепаратора ряда k смещены на φk mod 360°/n; расчёт — egm/ptk.py: phasing(), таблица — SPEC-10.
- Д-31: кинематика и профиль ПТК (схема Д-11, радиальные пазы сепаратора): u = n = z − 1, сепаратор вращается против входа; для заданного u берётся z = u + 1 (X-06); профиль венца — эквидистанта на ρ траектории центра тела r(t), e = min(ecc_k·Ø тела, e_margin·e_max); расчёт — egm/ptk_profile.py, формулы — SPEC-10; GEOM_REV = 2.
- Д-33: крепление венца — набор конфигураций ptk_input → ring_mounts; mount_mode: first_ok — первая прошедшая проверки, all — все; ключ крепления — поле mount, состав отверстий — в ID (Д-22); старый ring_holes читается как единственное крепление default.
- Д-34: передача усилия ПТК: угол профиля tg γ = r′/r; Fr = Ft/tg γ, N = Ft/sin γ, η с трением по (11); gap_k не задаётся, а подбирается для каждого (u, тело, крепление): наименьший из [gap_k_min; gap_k_max] с γ max ≥ gamma_min; γ ≤ φ — ошибка «заклинивание»; формулы — SPEC-10, код — egm/ptk_profile.py; GEOM_REV = 3.
- Д-35: Ø окр. отв. и Øнар округляются вверх до d_bc_step/d_out_step (0.1 / 1 мм); диаметры профиля не округляются — их задаёт кинематика.
- Д-36: концепция ПТК — specs/concept_ptk.png: эксцентрик с отверстиями балансировки, сепаратор с радиальными пазами, венец; каждый ряд уравновешивается отдельно (4 ряда 0/90/180/270° дают нулевую силу, но не момент): Δm·r_h = (m_диска + m_подш + n·m_тела/2)·e — CP-28.
- Д-37: обозначения ПТК — по Янгулову (docs/Силовой расчет ПТК): D_ш/Drol — тело, D_г/Dgen — генератор, a_ω/a_w — эксцентриситет, R_Σ = 0.5(D_г + D_ш)/R_sum, D_В/d_root — впадины, D_отв/d_bc, D/d_out — наружный; D — диаметр, R — радиус; тело — roller, раздел rollers; Ø дел. из таблицы SPEC-10 убран.
- Д-38: порядок расчёта ПТК по эталону egm/calc_vptc.py и Янгулову: a_ω = a_k·D_ш (0.2) или a_w тела; R_Σ — наименьший по трём условиям: подрез (r вершины ≥ r_tip_min), перемычка сепаратора ≥ sep_web_min, D_г ≥ Dgen_min; профиль — (6) + эквидистанта D_ш/2 под углом α; α max, (8), (9) — результаты; отменяет подбор gap_k (Д-34, X-07); GEOM_REV = 4.
- Д-41: допускаемый момент (egm/ptk_force.py): R_i = R_max·sin φ_i на 0 < φ < π, реакции (8), (9) без трения; Герц тело/наружное кольцо и тело/венец (венец — плоскость), [σ_H] — sigma_H_line/sigma_H_point; статика подшипника R_max·|Σ sin φ·e| ≤ C0/s0_brg; худшее из 8 положений генератора; M = min(M_H, M_B, M крепл./safety), ограничение — в SPEC-10; ошибка — только M < M_min; не учтены: трение (11), ресурс подшипника, контакт тело/паз (OQ-08, CP-31).
- Д-43: d_out_max — параметр конфигурации: 110 мм — для станков и оснастки EG-MACHINES (Д-08), допустимо любое значение или null — без предела (Dш max не считается); каталог bearings дополнен 61817…61820 (D до 125 мм, ориентировочно, OQ-09).
