# DECISIONS — журнал решений и открытые вопросы

Решения нумеруются `Д-##` общие для проекта, либо `Д-##.####` относящееся к конкретному станку, группируются по типам и не переписываются: при отмене решение помечается как
отменённое со ссылкой на заменившее. Открытые вопросы — `OQ-##`, закрытые
остаются в списке с пометкой и ссылкой на решение.

| Д-16 | Внешний венец (жёсткое колесо) ПТК несёт крепёжные отверстия на окружности между профилем впадин и наружным Ø; они же — технологические базы при изготовлении (крепление на оснастке станков). ~~Число отверстий кратно 4 (индексация 0/90/180/270°, совпадает с фазировкой рядов)~~ — отменено → Д-19 (X-04); штифтовые отверстия H7 между болтами — угловое базирование. Отверстия входят в расчёт Øнар и Ø тела max, момент удержания крепежом проверяется. Параметры — `specs/ptk_input.json` | rev 1   |
| Д-17 | К code-first спецификациям ведутся инструкции `instructions/INS-##_*.md`: входные файлы, параметры, обозначения. Номер совпадает со спецификацией (INS-10 ↔ SPEC-10); общий глоссарий — `instructions/README.md` (INS-00) | rev 1   |
| Д-18 | Входные параметры расчётов хранятся в `specs/*_input.json` и правятся заказчиком; значения по умолчанию в коде используются только в self_test | rev 1   |
| Д-19 | Число отверстий венца ПТК — любое. Фаза ряда φk (Д-08) — поворот эксцентрика генератора; ряд k — копия ряда 1, повёрнутая на φk. Отверстия пакета сквозные и совпадают, поэтому каждый венец сверлится со своим сдвигом: в системе профиля (впадина 0 на 0°) s_k = (−φk) mod g, g = 360°/НОК(z, N), N — порядок симметрии сверловки (болты + штифты). Равные s — один вариант венца. Гнёзда сепаратора ряда k смещены на φk mod 360°/n. Расчёт — `egm/ptk.py: phasing()`, таблица — SPEC-10 | rev 2   |
