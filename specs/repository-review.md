Если через WEB интерфейс контекст не читается, ИИ может читать репозиторий через GitHub REST API: `/repos/euginb/HarmonicV2/commits` (база патча — последний sha), `/git/trees/<sha>?recursive=1` (состав), `/contents/<путь>?ref=<sha>` (содержимое в base64, крупные файлы — по частям). raw.githubusercontent.com для крупных файлов отдаёт сжатый ответ, который инструмент ИИ может не прочитать.
5. Дополнительный способ чтения файлов ИИ: (1) `raw.githubusercontent.com/euginb/HarmonicV2/<sha>/<путь>` — текстовые файлы до ~10 КБ; (2) `/contents/<путь>?ref=<sha>` — base64 по частям; (3) запасной — `https://cdn.jsdelivr.net/gh/euginb/HarmonicV2@<sha>/<путь>` (файл целиком; `.py` может отдаваться как `application/octet-stream` — тогда (1) или (2))
